# 일본어 문장 분석

입력: `$ARGUMENTS` (일본어 텍스트)

## 동작 흐름

1. 오늘 날짜(`YYYY-MM-DD`)의 학습 노트 파일을 `media/`, `sjpt/` 에서 찾는다.
2. 파일 내에서 `$ARGUMENTS` 텍스트를 검색한다.

### 케이스 A: 문장 전체 (노트에 해당 텍스트가 한 줄로 존재)

- 그 줄 끝에 ` — 한글 뜻`을 추가한다.
- 예시: `本を読ませられなかった` → `本を読ませられなかった — 책을 읽게 시킬 수 없었다`
- 문장 내에 동사 활용형이 있으면, 번역 추가 후 바로 아래에 변형 분해도 함께 추가한다.

### 케이스 B: 활용형 일부 (노트에 이미 뜻이 추가된 문장의 일부분)

- `$ARGUMENTS`를 포함하는 문장을 찾는다.
- 해당 문장 바로 아래에 동사 변형 분해를 추가한다.
- **첫 줄(원형)에만** 후리가나를 `(よむ)` 형식으로 표기한다.
- 문장에서 활용형 외 부분(조사, 목적어 등)은 첫 줄에만 포함하고, 변형 단계에서는 생략한다.

## 변형 분해 출력 형식

변형 분해 블록은 `>` blockquote로 감싸서 본문 문장과 시각적으로 구분한다.

```
> 動詞原形 (후리가나) — 한글 뜻
> → 1단계 변형 — 한글 뜻 [변형 이름]
> → 2단계 변형 — 한글 뜻 [+변형 이름]
> → 3단계 변형 — 한글 뜻 [+변형 이름]
```

한 문장에 여러 동사가 있을 경우, 같은 blockquote 안에서 `>` 빈 줄로 구분한다.

### 변형 이름 규칙

- 첫 변형은 `[변형 이름]` (예: `[사역]`)
- 이후 누적 변형은 `[+변형 이름]` (예: `[+수동]`, `[+부정]`)

### 주요 변형 이름 목록

- 사역: ~せる/~させる
- 수동: ~れる/~られる
- 부정: ~ない
- 과거: ~た/~だ/~かった/~なかった
- 가능: ~える/~られる
- 의지: ~よう/~おう
- 사역수동: ~せられる/~させられる (한 단계로 묶어도 됨)
- て형: ~て/~で
- ば형(조건): ~ば/~れば
- たい(희망): ~たい
- 경어: ~ます

## 실제 예시

입력 문장: `本を読ませられなかった`
활용형 지정: `読ませられなかった`

노트에 기록되는 결과:

```
本を読ませられなかった — 책을 읽게 시킬 수 없었다

> 読む (よむ) — 읽다
> → 読ませる — 읽게 하다 [사역]
> → 読ませられる — 읽게 시킴을 당하다 [+수동]
> → 読ませられない — 읽게 시킴을 당할 수 없다 [+부정]
> → 読ませられなかった — 읽게 시킴을 당할 수 없었다 [+과거]
```

## 규칙

1. `$ARGUMENTS`가 비어 있으면 안내 후 중단.
2. 오늘 날짜 노트 파일이 없으면 안내 후 중단.
3. 파일에서 텍스트를 찾을 수 없으면 안내 후 중단.
4. 변형 분해 시 각 단계의 한글 뜻은 자연스러운 한국어로 번역한다.
5. 완료 후 수행한 작업을 간단히 알려준다.
