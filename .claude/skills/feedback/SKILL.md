# 일본어 번역 피드백

입력: `$ARGUMENTS`

## 입력 형식

사용자는 `|`로 구분하여 한글 뜻과 자신의 일본어 번역을 제공한다.

```
한글 문장 | 사용자의 일본어 번역
```

예시: `나는 어제 친구와 영화를 봤다 | 昨日友達と映画を見ました`

## 동작 흐름

1. `$ARGUMENTS`가 비어 있거나 `|` 구분자가 없으면 사용법을 안내 후 중단.
2. 한글 뜻과 사용자의 일본어 번역을 분리한다.
3. 일본어 원어민 관점에서 사용자의 번역을 검토한다.
   - 문법적 오류가 있는지
   - 더 자연스러운 표현이 있는지
   - 어휘 선택이 적절한지
   - 뉘앙스가 원래 의미와 맞는지
4. 결과를 아래 출력 형식으로 제공한다.

## 출력 형식

### 1. diff 블록

````markdown
```diff
- 사용자가 작성한 일본어 문장
+ 피드백 반영된 일본어 문장
```
````

- 사용자의 문장이 완벽하면 `+` 줄 없이 칭찬 코멘트만 남긴다.
- 부분 수정이면 해당 부분만 변경하고, 전체 문장을 다시 작성하지 않는다.
- 여러 가지 대안이 있으면 `+` 줄을 여러 개 제시할 수 있다.

### 2. 코멘트

diff 블록 아래에 수정 이유를 설명한다:

- **어휘**: 단어 선택 이유 (왜 이 단어가 더 자연스러운지)
- **문법**: 문법 수정 사항 설명
- **뉘앙스**: 원래 한글 의미와의 뉘앙스 차이
- **표현**: 원어민이 실제로 쓰는 관용적 표현 소개

해당하는 항목만 작성한다. 모든 항목을 억지로 채울 필요 없다.

## 예시

입력: `나는 어제 친구와 영화를 봤다 | 昨日友達と映画を見ました`

출력:

```diff
- 昨日友達と映画を見ました
+ 昨日友達と映画を観ました
```

- **어휘**: 映画やテレビなど映像作品には「観る(みる)」を使うのが一般的です。「見る」は"目で見る"という広い意味で、「観る」は"鑑賞する"というニュアンスがあります。

## 규칙

1. `$ARGUMENTS`가 비어 있으면 사용법을 안내 후 중단.
2. `|` 구분자가 없으면 사용법을 안내 후 중단.
3. 코멘트는 일본어로 작성하되, 핵심 뜻은 한국어를 병기한다.
4. 사용자의 문장이 이미 자연스러우면 억지로 수정하지 않고 잘 쓴 점을 칭찬한다.
5. 구어체/문어체, 경어/반말 등 문체는 사용자의 원문을 따른다.
