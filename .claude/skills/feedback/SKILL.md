# SJPT 일본어 말하기 피드백

입력: `$ARGUMENTS`

## 대상

이 스킬은 SJPT(Speaking Japanese Proficiency Test) 학습용으로, `sjpt/` 폴더의 마크다운 파일과 함께 사용한다.

## SJPT 시험 개요

총 7개 파트, 26문항, 시험시간 약 30분.

| 파트 | 유형                          | 문항 | 준비(초) | 응답(초) | 특징                                   |
| ---- | ----------------------------- | ---- | -------- | -------- | -------------------------------------- |
| 1부  | 自己紹介 (자기소개)           | 4    | 0        | 10       | 워밍업, 이름·취미·직업 등              |
| 2부  | 簡単な応答 (그림 보고 답하기) | 4    | 3        | 6        | 의문사(何·誰·どこ), 형용사·동사 활용   |
| 3부  | 敏速な応答 (대화 완성)        | 5    | 2        | 15       | 그림 상황 듣고 맥락에 맞게 답하기      |
| 4부  | 短い応答 (짧은 응답)          | 5    | 15       | 25       | 일상 화제에 대해 자신의 견해 말하기    |
| 5부  | 長い応答 (의견 제시)          | 4    | 30       | 50       | 사회 문제에 대해 논리적으로 의견 제시  |
| 6부  | 場面設定 (상황 대응)          | 3    | 30       | 40       | 주어진 상황에서 적절한 경어/반말 구사  |
| 7부  | 連続した絵 (스토리 구성)      | 1    | 30       | 90       | 4컷 그림 보고 스토리 설명, 접속사 활용 |

## 레벨 기준 (목표: Level 9~10)

- **Level 10**: 어떤 질문에도 폭넓은 어휘·문법으로 유창하게 답변. 사회 문제 등 다양한 분야에서 논리적 의견 제시. 모국어 영향 최소.
- **Level 9**: 공식적·고급 화제에도 논리적 의사소통. 구문 오류 거의 없음. 전문 분야 광범위 어휘 구사. 모국어 영향 적음.
- **Level 8**: 익숙하지 않은 상황에서도 적절히 대응. 고급 주제에서 속도 저하 가능. 모국어 영향 약간.

## 입력 형식

사용자는 `|`로 구분하여 한글 뜻과 자신의 일본어 번역을 제공한다.

```
한글 문장 | 사용자의 일본어 번역
```

예시: `나는 어제 친구와 영화를 봤다 | 昨日友達と映画を見ました`

## 동작 흐름

1. `$ARGUMENTS`가 비어 있거나 `|` 구분자가 없으면 사용법을 안내 후 중단.
2. 한글 뜻과 사용자의 일본어 번역을 분리한다.
3. 오늘의 sjpt 학습 노트(`sjpt/YYYY-MM-DD.md`)를 읽어 `## Part` 섹션에서 해당 파트 문맥을 파악한다.
4. 일본어 원어민 관점 + SJPT 고득점 관점에서 검토한다.
   - 문법적 오류가 있는지
   - 더 자연스러운 표현이 있는지
   - 어휘 선택이 적절한지
   - 한글 원문은 의도 파악용 참고일 뿐, 직역보다 자연스러운 일본어 표현을 우선한다
   - **SJPT 고득점 관점**:
     - 논리적 구성이 되어 있는지 (5부: 주장→이유→구체례→결론)
     - 경어/반말이 상황에 맞는지 (6부)
     - 접속사가 적절히 사용되었는지 (7부: それから、そして、すると、その後 등)
     - 응답 시간 내에 전달할 수 있는 분량인지
     - 고급 어휘·문법을 활용하고 있는지 (Level 9~10 목표)

## 출력 형식

### 1. diff 블록

````markdown
```diff
- 사용자가 작성한 일본어 문장
+ 피드백 반영된 일본어 문장
```
````

- 사용자의 문장이 완벽하면 수정 없이 고득점 팁만 제시한다.
- 부분 수정이면 해당 부분만 변경하고, 전체 문장을 다시 작성하지 않는다.
- 여러 가지 대안이 있으면 `+` 줄을 여러 개 제시할 수 있다.

### 2. 코멘트

diff 블록 아래에 수정 이유를 설명한다:

- **어휘**: 단어 선택 이유 (왜 이 단어가 더 자연스러운지)
- **문법**: 문법 수정 사항 설명
- **뉘앙스**: 원래 한글 의미와의 뉘앙스 차이
- **표현**: 원어민이 실제로 쓰는 관용적 표현 소개
- **SJPT**: 해당 파트에서 고득점을 위한 전략적 조언 (해당 시에만)

해당하는 항목만 작성한다. 모든 항목을 억지로 채울 필요 없다. 수정한 내용에 대해서만 설명하고, "적절하다", "잘 사용했다" 등의 칭찬은 쓰지 않는다.

### 3. 고득점 팁 (해당 시)

Level 9~10 달성을 위해 추가로 활용할 수 있는 고급 표현이나 논리 구성 패턴이 있으면 제안한다.

## 예시

입력: `나는 어제 친구와 영화를 봤다 | 昨日友達と映画を見ました`

출력:

```diff
- 昨日友達と映画を見ました
+ 昨日友達と映画を観ました
```

- **어휘**: 영화나 TV 등 영상 작품에는 「観る」를 쓰는 게 일반적이다. 「見る」는 "눈으로 보다"라는 넓은 의미이고, 「観る」는 "감상하다"라는 뉘앙스이다.

## 파일 기록

피드백 결과를 터미널에 표시한 후, 오늘의 학습 노트(`sjpt/YYYY-MM-DD.md`)에도 기록한다.

- 파일 끝에 `## Feedback` 섹션을 추가하고 피드백 내용(diff 블록 + 코멘트)을 기록한다.
- `## Feedback` 섹션이 이미 존재하면 해당 섹션 끝에 이어서 추가한다 (새 섹션을 만들지 않는다).
- 기록 형식은 터미널 출력과 동일하다 (diff 블록 + 코멘트 + 고득점 팁).

## 약점 노트 업데이트

피드백을 학습 노트에 기록한 후, 수정 사항이 있으면 `weakness/` 파일을 업데이트한다.

### 업데이트 절차

1. 각 수정 포인트의 카테고리(문법/어휘/표현)와 패턴을 판별한다.
2. 해당 패턴이 이미 `weakness/` 파일에 존재하면:
   - 해당 패턴의 테이블 **맨 위**(헤더 행 바로 아래)에 새 행을 추가한다 (날짜, 출처: sjpt, 한글 원문, 틀린 표현, 올바른 표현, 설명).
   - 횟수를 +1 한다.
   - 해당 패턴이 졸업 상태(`연속통과: 3`)이면, `연속통과`를 0으로, `다음복습`을 오늘 날짜로 변경한다.
3. 해당 패턴이 없으면:
   - 해당 카테고리 파일(`grammar.md`, `vocabulary.md`, `expression.md`)에 새 섹션을 추가한다.
4. `weakness/index.md`의 테이블을 갱신한다:
   - 횟수 업데이트
   - 최근 발생 날짜 업데이트
   - 상태 재계산: 🔴 (5회+), 🟡 (2~4회), 🟢 (최근 5일 무발생)
   - 최종 갱신 날짜 업데이트

### 패턴 분류 기준

기존 패턴에 매칭할 때는 다음 기준을 사용한다:

- **문법**
  - 조사 누락/오용: 조사(が/を/に/で/の/と/から/まで 등)가 빠지거나 잘못 쓰인 경우
  - 동사 활용형 오류: て형, た형, ない형, ば형 등 활용이 틀린 경우. い/な형용사 활용 포함
  - ~ている 누락: 상태/지속/결과를 나타내는 「ている」가 빠진 경우
  - 가능형 누락/오용: "~할 수 있다"의 가능형 관련 오류
  - ~なくて vs ~ないで/ず: 이유 vs 부대상황 혼동
  - 조건형 선택 오류: ば/たら/と/なら 선택 오류
  - 기타 문법 오류: 위에 해당하지 않는 문법 오류
- **어휘**
  - 유사어 혼동: 뜻이 비슷하지만 뉘앙스가 다른 단어 혼동
  - 카타카나 표기 오류: 외래어 카타카나 표기 실수
  - 구어↔문어 혼용: 상황에 맞지 않는 구어/문어 어휘 선택
  - 한자 표기 오류: 동음이의 한자 혼동
- **표현**
  - 경어 수준 오류: 겸양어/존경어 관련 오류
  - 문말/종조사 오류: ね/な/よ/よね/んだ 등 종조사 선택 오류
  - 문체 불일치: 경어↔반말 혼용, 파트별 톤 불일치
  - 접속사 오류: そして/すると/そこで 등 접속사 선택 오류

## 규칙

1. `$ARGUMENTS`가 비어 있으면 사용법을 안내 후 중단.
2. `|` 구분자가 없으면 사용법을 안내 후 중단.
3. 코멘트 설명은 반드시 한국어로 작성한다. 일본어는 수정 대상 단어·표현을 인용할 때(「」로 감싼 짧은 인용)만 사용하고, 그 외 문장·설명·해설은 모두 한국어로 쓴다. 일본어로 긴 문장을 쓰지 않는다.
4. 사용자의 문장이 이미 자연스러우면 억지로 수정하지 않는다. 칭찬은 쓰지 않고 고득점 팁만 제시한다.
5. 구어체/문어체, 경어/반말 등 문체는 사용자의 원문을 따른다.
6. 항상 Level 9~10 기준으로 피드백한다. 문법적으로 틀리지 않더라도 더 고급스러운 표현이 있으면 제안한다.
7. 파트별 응답 시간을 고려하여 비현실적으로 긴 답변은 지양하도록 조언한다.
8. 피드백 결과는 반드시 학습 노트 파일에 기록한다.
9. 피드백에 수정 사항이 있으면 반드시 `weakness/` 파일을 업데이트한다.
