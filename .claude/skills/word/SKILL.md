# 일본어 단어 추가

입력: `$ARGUMENTS`

## 입력 형식

사용자는 마크다운 테이블 형식으로 단어를 제공한다. **모든 칸이 비어 있을 수 있다.**

```
| 일본어 | 발음 | 한글 뜻 |
| --- | --- | --- |
|  | たべる |  |
|  |  | 달리다 |
| 食べる |  |  |
```

- 세 칸 중 최소 하나는 채워져 있어야 한다.
- 어떤 칸이든 채워져 있으면 그것을 단서로 나머지 빈 칸을 추론하여 채운다.

## 동작 흐름

1. `$ARGUMENTS`가 비어 있으면 사용법을 안내 후 중단.
2. 테이블에서 각 행을 파싱한다.
3. 빈 칸을 채운다:
   - **일본어**: 발음이나 한글 뜻을 단서로 적절한 일본어(한자 포함)를 기입한다. (예: 발음 `たべる` → `食べる`)
   - **발음**: 히라가나로 읽는 법을 기입한다. (예: `たべる`, `はしる`)
   - **한글 뜻**: 한국어 뜻을 간결하게 기입한다. (예: `먹다`, `달리다`)
   - 이미 채워진 칸은 그대로 유지한다.
4. 오늘 날짜(`YYYY-MM-DD`)의 학습 노트 파일을 `media/`, `sjpt/`, `sudden/` 에서 찾는다.
5. 파일 내 word 섹션(`### word` 또는 `## word`)의 테이블에 단어 행을 추가한다.
   - 기존 빈 행(`|  |  |  |`)은 제거한다.
   - 기존에 이미 있는 단어 행은 유지하고, 새 단어를 아래에 추가한다.

## 출력 형식

완성된 테이블을 화면에 보여준 뒤, 노트 파일에 기록한다.

```
| 일본어 | 발음 | 한글 뜻 |
| --- | --- | --- |
| 食べる | たべる | 먹다 |
| 走る | はしる | 달리다 |
```

## 규칙

1. `$ARGUMENTS`가 비어 있으면 사용법을 안내 후 중단.
2. 오늘 날짜 노트 파일이 없으면 안내 후 중단.
3. 발음은 히라가나로만 표기한다 (카타카나 단어는 카타카나 유지).
4. 한글 뜻은 가장 대표적인 뜻을 간결하게 작성한다.
5. 완료 후 추가된 단어 수를 간단히 알려준다.
