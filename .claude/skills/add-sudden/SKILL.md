# 한글 문장 추가

## 동작 흐름

1. `$ARGUMENTS`에서 파일 경로와 한글 문장들을 파싱한다.
2. 파일 경로가 없으면 Bash로 `date -v-4H '+%Y-%m-%d'` 명령을 실행하여 학습일을 구하고 (KST 새벽 4시 기준, 자정~03:59는 전날 날짜 사용), 해당 날짜의 `sudden/YYYY-MM-DD.md`를 기본으로 사용한다.
3. 파일을 읽어 **내용이 비어있는 `## 한글` + `## 일본어` 쌍**이 있는지 확인한다. (템플릿으로 생성된 빈 섹션)
4. 각 한글 문장의 맞춤법을 검사하고, 틀린 부분이 있으면 수정한다.
5. 문장마다 다음 순서로 처리한다:
   a. 파일에 내용이 비어있는 `## 한글` 섹션이 있으면 → 그 섹션에 문장을 채우고, 바로 아래 비어있는 `## 일본어` 섹션에 `-`를 채운다.
   b. 이미 같은 문장이 파일에 존재하면 → 건너뛴다.
   c. 위 둘 다 해당 없으면 → 파일 끝에 새로운 `## 한글` + `## 일본어` 쌍을 추가한다.

## 인자 파싱 규칙

- 문장 구분자는 `/`이다.
- 첫 번째 인자가 `.md`로 끝나는 경로이면 파일 경로로 인식한다.
- 파일 경로가 없으면 `sudden/YYYY-MM-DD.md`를 사용한다.

예시:

- `/add-sudden sudden/2026-03-16.md 오늘 점심 든든하네 / 태양이 5개입니다`
- `/add-sudden 오늘 점심 든든하네 / 태양이 5개입니다` → `sudden/YYYY-MM-DD.md`에 추가

## 출력 형식

파일 끝에 각 문장마다 아래 형식을 추가한다:

```markdown
## 한글

- 한글 문장

## 일본어

-
```

## 규칙

1. 대상 파일이 존재하지 않으면 안내 후 중단한다.
2. 문장이 하나도 없으면 안내 후 중단한다.
3. 각 문장의 앞뒤 공백을 제거한다.
4. 맞춤법이 틀린 부분이 있으면 수정 후 기록한다. 수정한 경우 원문과 수정문을 함께 알려준다.
5. 비어있는 `## 한글` 섹션 판단 기준: `## 한글` 줄 다음에 내용(문장)이 없고, 바로 `## 일본어` 또는 다음 `##` 섹션이 오는 경우.
6. 파일에 이미 같은 한글 문장이 존재하면 추가하지 않는다. 건너뛴 문장이 있으면 완료 시 알려준다.
7. 새 섹션을 파일 끝에 추가할 때, 파일 끝에 빈 줄이 없으면 빈 줄을 먼저 추가한다.
8. 완료 후 채운/추가한 문장 수(건너뛴 문장 수 포함)와 파일 경로를 알려준다.
