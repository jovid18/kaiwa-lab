# 약점 복습

입력: `$ARGUMENTS`

## 핵심 개념: 라운드 로빈 복습

테이블 순서 자체가 우선순위다. 각 패턴 테이블의 **상위 5개 행**을 출제하고, 맞힌 문장은 테이블 맨 아래로 이동한다. 별도의 state.json 없이 weakness 파일만으로 복습을 관리한다.

## 동작 흐름

### 1단계: 복습 패턴 선정

1. `weakness/grammar.md`, `weakness/vocabulary.md`, `weakness/expression.md`를 읽는다.
2. 각 패턴 섹션의 헤더에서 `연속통과`와 `다음복습`을 파싱한다.
3. `$ARGUMENTS`에 따라 대상 범위를 결정한다:
   - `grammar`: grammar.md의 패턴만
   - `vocabulary`: vocabulary.md의 패턴만
   - `expression`: expression.md의 패턴만
   - `all` 또는 비어 있음: 전체 패턴
4. 복습 대상 필터링:
   - 졸업 패턴(`연속통과 >= 3`) 제외
   - `다음복습`이 오늘 이하이거나 비어 있는 패턴만 선정
5. 활성 테이블 행 수가 많은 순으로 정렬한다.
6. 상위 **5개 패턴**을 선정한다.

### 1-1단계: 졸업 패턴 재활성화 체크

각 패턴에서 `연속통과 >= 3`이지만 활성 테이블에 행이 있으면 (새 오류가 추가된 것), `연속통과`를 0으로, `다음복습`을 오늘로 변경하고 복습 대상에 포함한다.

### 2단계: 대표 문장 선정

각 패턴에서 활성 테이블의 **상위 5개 행**을 그대로 가져온다.

추가 규칙:

- 한글 원문이 있는 항목만 선정
- 활성 테이블 행이 5개 미만이면 있는 만큼만 선정

### 3단계: HTML 파일 생성

`review/session.html` 파일을 생성한다. 이 파일에 출제 데이터와 채점 로직을 모두 포함한다.

#### HTML 구조

```html
<!DOCTYPE html>
<html lang="ko">
  <head>
    <meta charset="UTF-8" />
    <title>복습</title>
    <style>
      /* 스타일 */
    </style>
  </head>
  <body>
    <!-- 한 문장씩 표시하는 카드 UI -->
    <!-- 입력 필드 + 다음 버튼 -->
    <!-- 마지막: 전체 채점 결과 + 결과 복사 버튼 -->
    <script>
      const questions = [
        /* 출제 데이터 */
      ];
      // 채점 로직, UI 로직, 결과 코드 생성
    </script>
  </body>
</html>
```

#### HTML UI 흐름

1. **출제 화면**: 전체 문장을 한 페이지에 나열
   - 각 문장은 카드 형태로 표시
   - 한글 원문 전체를 보여주되, 이전에 틀렸던 부분을 `<strong>` 태그로 강조
   - 각 카드 아래에 입력 필드 (볼드 부분의 일본어를 입력)
   - **패턴명, 카테고리, 출처는 보여주지 않는다**
   - 문장 순서는 패턴별로 묶지 않고 **랜덤하게 섞는다**
   - 맨 아래 **"채점" 버튼**

2. **채점 화면**: "채점" 버튼 클릭 후 같은 페이지에서 결과를 표시
   - 각 카드에 ✅/❌ 표시 추가
   - 틀린 경우: 사용자 답안 + 정답 + 설명 표시
   - 맞은 경우: 간단히 ✅만 표시
   - 페이지 상단에 패턴별 종합 결과 표시
   - 맨 아래: **"결과 복사" 버튼** — 클릭 시 결과 JSON을 클립보드에 복사, "복사됨!" 텍스트로 변경

#### questions 데이터 구조

```javascript
const questions = [
  {
    id: 1,
    korean: '확실히 사람이 <strong>많지 않아서</strong> 한산하군',
    boldText: '많지 않아서',
    answer: '多くなくて',
    wrong: '多くじゃなくて',
    explanation: 'い형용사 부정은 「くない」',
    pattern: 'grammar:동사 활용형 오류',
  },
  // ...
];
```

#### 결과 JSON 형식

"결과 복사" 버튼 클릭 시 클립보드에 복사되는 JSON:

```json
{
  "date": "2026-03-25",
  "results": {
    "grammar:조사 누락/오용": {
      "sentences": {
        "03-24:友達ように": { "input": "友達のように", "answer": "友達のように", "pass": true },
        "03-25:8時50分に": { "input": "8時50分ごろに", "answer": "8時50分ごろに", "pass": true },
        "03-20:お腹空いて": { "input": "お腹空いて", "answer": "お腹が空いて", "pass": false }
      }
    },
    "vocabulary:유사어 혼동": {
      "sentences": {
        "03-25:評判": { "input": "評価", "answer": "評価", "pass": true },
        "03-24:詰まれば": { "input": "溜まれば", "answer": "溜まったら", "pass": false }
      }
    }
  }
}
```

- 각 문장에 `input`(사용자 입력), `answer`(정답), `pass`(HTML 채점 결과)를 포함한다.
- HTML 채점은 **완전 일치** 기준으로 엄격하게 판정한다 (공백/전각반각 차이만 무시).

#### 채점 기준 (HTML 내 JavaScript)

- 사용자 입력과 `answer`를 비교한다.
- **완전 일치**면 ✅
- 불일치면 ❌
- 공백, 전각/반각 차이는 무시한다.

### 4단계: 브라우저에서 열기

`open review/session.html` 명령으로 브라우저에서 HTML 파일을 연다.

사용자에게 안내:

```
복습 세션을 브라우저에서 열었습니다.
완료 후 결과를 복사해서 여기에 붙여넣어 주세요.
```

### 5단계: 결과 반영 (CLI 재채점)

사용자가 결과 JSON을 CLI에 붙여넣으면:

1. JSON을 파싱한다.
2. HTML에서 `pass: false`인 문장의 `input`과 `answer`를 재검토한다.
   - 이전 실수 포인트가 교정되었고, 문법적으로 정확하고 자연스러운 표현이면 **pass로 변경**한다.
   - 예: 정답 「溜まったら」, 입력 「溜まれば」 → 이전 실수(詰まれば→溜まる)의 핵심인 어휘 선택은 교정됨 → pass
3. 재채점으로 변경된 항목이 있으면 사용자에게 보여준다:
   ```
   ### 재채점
   - Q5: 「溜まれば」→ 이전 실수(詰まれば)는 교정됨 → ✅로 변경
   ```
4. 최종 결과로 weakness 파일을 업데이트한다 (아래 "결과 반영 규칙" 참조).
5. `review/progress.md`를 갱신한다.
6. `review/session.html`을 삭제한다.
7. CLI에 세션 요약을 표시한다.

### 결과 반영 규칙

각 패턴별로:

1. **맞힌 문장**: 활성 테이블에서 해당 행을 **맨 아래로 이동**한다.
2. **틀린 문장**: 제자리 유지 (이동하지 않음).
3. **패턴 통과 판정**: 해당 패턴의 모든 출제 문장이 pass면 통과.
   - **통과**: `연속통과` +1, `다음복습` 계산:
     - `연속통과 == 1` → 오늘 + 3일
     - `연속통과 == 2` → 오늘 + 7일
     - `연속통과 == 3` → 졸업 (아래 졸업 처리)
   - **실패**: `연속통과` → 0, `다음복습` → 내일

### 졸업 처리

`연속통과`가 3이 되면:

1. 활성 테이블의 모든 행을 `<details>` 섹션으로 이동한다.
2. 기존 `<details>` 섹션이 있으면 그 안의 테이블에 합친다.
3. 헤더를 업데이트한다:
   - `다음복습: 졸업`
4. `<details>` 형식:

```markdown
<details>
<summary>졸업한 문장 (N건)</summary>

| 날짜 | 출처 | 한글 원문 | 틀린 표현 | 올바른 표현 | 설명 |
| ---- | ---- | --------- | --------- | ----------- | ---- |
| ...  |

</details>
```

### 졸업 패턴 재활성화

졸업 패턴(`연속통과 >= 3`)에 `/translate`이나 `/feedback`으로 새 오류가 추가되면:

- 활성 테이블에 행이 존재함
- → `연속통과` → 0, `다음복습` → 오늘
- 기존 졸업 문장은 `<details>` 섹션에 그대로 유지

## 세션 요약

결과 반영 후 CLI에 표시:

```
## 복습 결과

| 패턴 | 결과 | 정답률 |
|------|------|--------|
| 조사 누락/오용 | ✅ 통과 | 3/3 |
| 유사어 혼동 | ❌ 재복습 | 1/2 |
| 동사 활용형 오류 | ✅ 통과 | 2/2 |

### 다음 복습 예정
- 내일: 유사어 혼동
- 3일 후: 조사 누락/오용, 동사 활용형 오류
```

## 규칙

1. 복습 대상이 없으면 "오늘 복습할 패턴이 없습니다"를 표시하고 중단한다.
2. 한글 원문이 없는 항목은 출제 대상에서 제외한다.
3. 설명은 한국어로 작성한다.
4. HTML 파일 생성 시 외부 라이브러리 없이 순수 HTML/CSS/JS만 사용한다.
5. HTML의 스타일은 깔끔하고 모바일에서도 사용 가능하게 반응형으로 만든다.
