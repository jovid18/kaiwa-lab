# 한글 → 일본어 번역 피드백

## 동작 흐름

1. 오늘 날짜(`YYYY-MM-DD`)의 `sudden/YYYY-MM-DD.md` 파일을 연다.
2. `## 한글` + `## 일본어` 쌍에서 아직 피드백되지 않은 항목을 찾는다.
3. 한글 원문과 사용자의 일본어를 비교하여 검토한다.
4. 수정이 필요하면 diff 블록으로 피드백한다.
5. 사용자의 문장이 자연스러우면 수정 없이 변형 분해만 기록한다.

## 출력 형식

`## 일본어` 아래에 diff + 수정 포인트 + 변형 분해를 기록한다:

````
## 일본어

- 사용자의 일본어 문장 (그대로 유지)

```diff
- 사용자가 작성한 일본어 문장
+ 수정된 일본어 문장
```

- **카테고리**: 「수정 전」→「수정 후」。설명.

> 동사원형 (후리가나) — 한글 뜻
> → 1단계 변형 — 한글 뜻 [변형 이름]
> → 2단계 변형 — 한글 뜻 [+변형 이름]
````

### 수정 포인트 규칙

- diff 블록 바로 아래에 수정 포인트를 기록한다.
- 각 포인트는 `「수정 전」→「수정 후」` 형식으로 before/after를 명시한다.
- 카테고리는 **문법**, **어휘**, **표현** 중 해당하는 것을 사용한다.
  - **문법**: 조사, 활용, 문형 등 문법적 오류
  - **어휘**: 단어 선택, 의미 차이
  - **표현**: 자연스러움, 경어 수준, 관용적 표현
- 사용자의 문장이 완벽하면 diff 블록과 수정 포인트 없이 변형 분해만 기록한다.
- diff의 `+` 줄은 하나만 제시한다.
- 변형 분해는 수정된 문장(diff의 `+` 줄) 기준으로 작성한다.

## 변형 분해 규칙

- 번역 문장의 각 동사/형용사에 대해 변형 분해를 작성한다.
- 한 문장에 여러 동사가 있을 경우, 같은 blockquote 안에서 `>` 빈 줄로 구분한다.
- **첫 줄(원형)에만** 후리가나를 `(よむ)` 형식으로 표기한다.

### 변형 이름 규칙

- 첫 변형은 `[변형 이름]` (예: `[사역]`)
- 이후 누적 변형은 `[+변형 이름]` (예: `[+수동]`, `[+부정]`)

### 주요 변형 이름 목록

- 사역: ~せる/~させる
- 수동: ~れる/~られる
- 부정: ~ない
- 과거: ~た/~だ/~かった/~なかった
- 가능: ~える/~られる
- 의지: ~よう/~おう
- 사역수동: ~せられる/~させられる
- て형: ~て/~で
- ば형(조건): ~ば/~れば
- たい(희망): ~たい
- 경어: ~ます
- 추측: ~そう/~だろう/~でしょう
- 이유: ~から/~ので/~て

## 실제 예시

입력 (sudden 노트):

```
## 한글

- 나는 어제 친구와 영화를 봤다

## 일본어

- 昨日友達と映画を見ました
```

출력 (기록 결과):

````
## 일본어

- 昨日友達と映画を見ました

```diff
- 昨日友達と映画を見ました
+ 昨日友達と映画を観ました
```

- **어휘**: 「見ました」→「観ました」。영화·공연 등을 감상하는 경우 「観る」를 쓴다. 「見る」는 단순히 시야에 들어오는 것을 의미.

> 観る (みる) — 보다 (감상하다)
> → 観ました — 봤습니다 [경어+과거]
````

## 약점 노트 업데이트

피드백을 학습 노트에 기록한 후, 수정 사항이 있으면 `weakness/` 파일을 업데이트한다.

### 업데이트 절차

1. 각 수정 포인트의 카테고리(문법/어휘/표현)와 패턴을 판별한다.
2. 해당 패턴이 이미 `weakness/` 파일에 존재하면:
   - 해당 패턴의 테이블 **맨 위**(헤더 행 바로 아래)에 새 행을 추가한다 (날짜, 출처: sudden, 한글 원문, 틀린 표현, 올바른 표현, 설명).
   - 횟수를 +1 한다.
   - 해당 패턴이 졸업 상태(`연속통과: 3`)이면, `연속통과`를 0으로, `다음복습`을 오늘 날짜로 변경한다.
3. 해당 패턴이 없으면:
   - 해당 카테고리 파일(`grammar.md`, `vocabulary.md`, `expression.md`)에 새 섹션을 추가한다.
4. `weakness/index.md`의 테이블을 갱신한다:
   - 횟수 업데이트
   - 최근 발생 날짜 업데이트
   - 상태 재계산: 🔴 (5회+), 🟡 (2~4회), 🟢 (최근 5일 무발생)
   - 최종 갱신 날짜 업데이트

### 패턴 분류 기준

기존 패턴에 매칭할 때는 다음 기준을 사용한다:

- **문법**
  - 조사 누락/오용: 조사(が/を/に/で/の/と/から/まで 등)가 빠지거나 잘못 쓰인 경우
  - 동사 활용형 오류: て형, た형, ない형, ば형 등 활용이 틀린 경우. い/な형용사 활용 포함
  - ~ている 누락: 상태/지속/결과를 나타내는 「ている」가 빠진 경우
  - 가능형 누락/오용: "~할 수 있다"의 가능형 관련 오류
  - ~なくて vs ~ないで/ず: 이유 vs 부대상황 혼동
  - 조건형 선택 오류: ば/たら/と/なら 선택 오류
  - 기타 문법 오류: 위에 해당하지 않는 문법 오류
- **어휘**
  - 유사어 혼동: 뜻이 비슷하지만 뉘앙스가 다른 단어 혼동
  - 카타카나 표기 오류: 외래어 카타카나 표기 실수
  - 구어↔문어 혼용: 상황에 맞지 않는 구어/문어 어휘 선택
  - 한자 표기 오류: 동음이의 한자 혼동
- **표현**
  - 경어 수준 오류: 겸양어/존경어 관련 오류
  - 문말/종조사 오류: ね/な/よ/よね/んだ 등 종조사 선택 오류
  - 문체 불일치: 경어↔반말 혼용, 파트별 톤 불일치
  - 접속사 오류: そして/すると/そこで 등 접속사 선택 오류

## 규칙

1. `sudden/YYYY-MM-DD.md` 파일이 없으면 안내 후 중단.
2. 처리할 한글 문장이 없으면 안내 후 중단.
3. 수정 포인트 설명은 반드시 한국어로 작성한다. 일본어는 수정 대상 단어·표현을 인용할 때(「」로 감싼 짧은 인용)만 사용하고, 그 외 문장·설명·해설은 모두 한국어로 쓴다. 일본어로 긴 문장을 쓰지 않는다.
4. 변형 분해 시 각 단계의 한글 뜻은 자연스러운 한국어로 번역한다.
5. 변형이 없는 단순 명사/조사는 분해하지 않는다. 동사·형용사·보조동사만 분해한다.
6. 사용자의 문장이 자연스러우면 억지로 수정하지 않는다.
7. 피드백에 수정 사항이 있으면 반드시 `weakness/` 파일을 업데이트한다.
8. 완료 후 수행한 작업을 간단히 알려준다.
