# 일본어 학습 팁 추가

입력: `$ARGUMENTS`

## 동작 흐름

1. `$ARGUMENTS`가 비어 있으면 사용법을 안내 후 중단.
2. 입력에서 **대상 파일 경로**, **팁 주제**, **팁 내용/설명**을 파악한다.
   - 파일 경로가 명시되지 않으면 오늘 날짜의 학습 노트(`sjpt/YYYY-MM-DD.md`)를 기본 대상으로 한다.
   - 팁 주제가 불명확하면 사용자에게 확인한다.
3. 대상 파일을 읽어 현재 내용을 확인한다.
4. 사용자가 제공한 내용을 바탕으로 `### Tip - [주제]` 형식의 섹션을 구성한다.
5. 대상 파일 끝에 팁 섹션을 추가한다.
6. 완료 후 경로와 추가된 팁 주제를 알려준다.

## 팁 섹션 형식

```markdown
### Tip - [주제]

[설명문]

| 열1 | 열2 | 열3 | ... |
| --- | --- | --- | --- |
| ... | ... | ... | ... |

> 주의/참고 사항 (필요 시)
```

## 형식 규칙

1. 헤딩은 항상 `### Tip - [주제]`로 시작한다.
2. 헤딩 아래에 간결한 설명문을 1~2줄로 작성한다.
3. 내용은 **테이블** 형식으로 정리한다.
   - 문법/활용형 팁: `| 축약형/변형 | 원형 | 의미 | 예시 |` 등의 열 구성
   - 어휘/단어 팁: `| 일본어 | 발음 | 한글 뜻 |` 또는 `| 축약어 | 원래 말 | 한글 뜻 |` 등의 열 구성
   - 팁 내용에 맞게 열 구성을 유연하게 조정한다.
4. 하위 분류가 있으면 `**소제목**`으로 구분하고 각각 테이블을 작성한다.
5. 주의사항이나 보충 설명은 `> 인용 블록`으로 추가한다.
6. 예시 문장에는 한글 뜻을 병기한다.
7. 발음이 헷갈릴 수 있는 한자어에는 후리가나를 괄호로 표기한다. (예: `就活(しゅうかつ)`)

## 내용 규칙

1. 사용자가 제공한 내용을 충실히 반영한다.
2. 사용자가 주제만 제시한 경우, 해당 주제에 대해 학습에 유용한 내용을 정리하여 작성한다.
3. 일본어 학습 관점에서 실용적이고 자주 쓰이는 내용을 우선한다.
4. 테이블의 예시 문장은 일상 회화에서 실제로 사용되는 자연스러운 문장으로 작성한다.
5. 코멘트는 한국어로 작성하되, 일본어 표현·문법 용어는 일본어 원문을 그대로 쓴다.

## 사용 예시

```
/tip sjpt/2026-03-09.md 축약형 (회화체) ~てる, ~ちゃう 등 회화에서 쓰는 축약형 정리
/tip 경어 존경어와 겸양어 구분 정리
/tip sjpt/2026-03-10.md 조사 비교 は vs が 차이점
```
