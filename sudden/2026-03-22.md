## 일본어

-　もう４月初め売れ切れなんていくら流行っているんじゃな。

```diff
- もう４月初め売れ切れなんていくら流行っているんじゃな。
+ もう４月初めまで売り切れだなんて、どんなに人気があるんだよ。
```

- **어휘**: 「売れ切れ」→「売り切れ」。올바른 표기는 「売り切れ」(送り仮名에 り 필요).
- **어휘**: 「いくら」→「どんなに」。「いくら」는 금액·수량을 물을 때 쓰고, 정도가 대단하다는 감탄에는 「どんなに」「どれだけ」를 쓴다.
- **어휘**: 「流行っている」→「人気がある」。「流行る」는 유행하다, 「人気がある」는 인기가 있다. 원문의 '인기가 많은'에 직접 대응.
- **문법**: 「んじゃな」→「んだよ」。「じゃな」는 노인 말투. 반말 감탄·강조에는 「んだよ」가 자연스럽다.
- **문법**: 「初め」→「初めまで」。'~까지'에 해당하는 조사 「まで」가 필요.

> 売り切れる (うりきれる) — 매진되다
> → 売り切れ — 매진 [명사화]
>
> ある — 있다
> → あるんだよ — 있는 거야 [설명+강조]

## 일본어

- 毎週月曜日夕方6時にチケットが解かれるな。

```diff
- 毎週月曜日夕方6時にチケットが解かれるな。
+ 毎週月曜日の夕方6時にチケットが発売されるんだな。
```

- **어휘**: 「解かれる」→「発売される」。「解く」는 문제를 풀다·매듭을 풀다. 티켓 판매 개시에는 「発売される」를 쓴다.
- **문법**: 「な」→「んだな」。'~구나'(깨달음)는 「んだな」가 자연스럽다.
- **문법**: 「月曜日夕方」→「月曜日の夕方」。요일과 시간대 사이에 「の」를 넣는 게 자연스럽다.

> 発売する (はつばいする) — 발매하다
> → 発売される — 발매되다 [수동]
> → 発売されるんだな — 발매되는구나 [+설명+감탄]

## 일본어

-　どのように母胎ソロとバツイチを繋ぐ配信を作ったんだな。

```diff
- どのように母胎ソロとバツイチを繋ぐ配信を作ったんだな。
+ どうやって母胎ソロとバツイチを繋ぐ番組を作ったんだろう。
```

- **표현**: 「どのように」→「どうやって」。구어체에서는 「どうやって」가 더 자연스럽다.
- **어휘**: 「配信」→「番組」。「配信」는 스트리밍·배포, 「番組」는 TV 프로그램·방송 프로그램.
- **문법**: 「んだな」→「んだろう」。'~었을까?'(의문·감탄)에는 「んだろう」가 대응. 「んだな」는 확인·납득의 뉘앙스.

> 繋ぐ (つなぐ) — 연결하다
>
> 作る (つくる) — 만들다
> → 作った — 만들었다 [과거]
> → 作ったんだろう — 만들었을까 [+설명+추측]

## 일본어

-　うん、そこでモチーフを得た

```diff
- うん、そこでモチーフを得た
+ うん、そこでモチーフを得たんだ
```

- **표현**: 「得た」→「得たんだ」。'~었어'(설명적 반말)에는 「んだ」를 붙여야 회화체로 자연스럽다. 「得た」만으로는 문어체처럼 딱딱하다.

> 得る (える) — 얻다
> → 得た — 얻었다 [과거]
> → 得たんだ — 얻었어 [+설명]

### Tip - んだ（説明・納得の文末表現）

한국어의 '~는 거야', '~구나'에 해당하는 설명·납득의 문말 표현. 단순 서술(だ/た)과 달리 **배경 설명·깨달음·감정**을 담는다.

**접속 방법**

| 품사     | 접속               | 예시                   |
| -------- | ------------------ | ---------------------- |
| 동사     | 동사 보통형 + んだ | 行くんだ、食べたんだ   |
| イ형용사 | い + んだ          | 高いんだ、よかったんだ |
| ナ형용사 | な + んだ          | 重要なんだ、静かなんだ |
| 명사     | な + んだ          | 学生なんだ、休みなんだ |

**문말 변형과 뉘앙스**

| 표현     | 뉘앙스                | 한국어 대응    | 예시                                 |
| -------- | --------------------- | -------------- | ------------------------------------ |
| んだ     | 설명·강조 (반말)      | ~는 거야       | そこで得たんだ (거기서 얻었어)       |
| んだよ   | 강조·주장 (반말)      | ~는 거야/~라고 | 人気があるんだよ (인기 있는 거야)    |
| んだな   | 납득·감탄 (반말)      | ~구나          | 重要なんだな (중요하구나)            |
| んだね   | 공감·확인 (반말)      | ~구나/~네      | そうなんだね (그렇구나)              |
| んです   | 설명·강조 (경어)      | ~는 거예요     | 行くんです (가는 거예요)             |
| んですか | 이유·사정 질문 (경어) | ~는 건가요?    | どうしたんですか (어떻게 된 건가요?) |

> んだ 없이 「得た」만 쓰면 문어체·보고체처럼 딱딱하다. 회화에서는 んだ를 붙여야 자연스럽다.
