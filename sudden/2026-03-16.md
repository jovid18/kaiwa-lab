## Feedback

```diff
- 早く起きることよりも早く寝ることが難しいと事実を絶対忘れないよ
+ 早く起きることよりも早く寝ることが難しいという事実を絶対忘れるなよ
```

- **문법**: 「難しいと事実」→「難しいという事実」. 절(clause)을 명사에 연결할 때는 「という」가 필요하다. 「～という事実」로 "~라는 사실"이라는 의미가 된다.
- **문법**: 「忘れないよ」→「忘れるなよ」. 「忘れないよ」는 "안 잊어" (자신의 의지)라는 뜻이고, 한글 원문 "잊지마"는 명령/금지이므로 「忘れるな」(~하지 마)를 써야 한다. 「よ」를 붙이면 친근한 어감이 된다.

### Tip - 명령·금지 표현 문법

동사의 명령형(~해라)과 금지형(~하지 마)은 반말 회화에서 자주 쓰인다. 「ないで」는 부드러운 부탁, 「な」는 강한 금지이다.

**명령형 (～しろ / ～해라)**

| 활용 그룹      | 만드는 법            | 예시                    | 의미     |
| -------------- | -------------------- | ----------------------- | -------- |
| 5단(う단→え단) | 어미를 え단으로 변환 | 書(か)く → 書(か)け     | 써라     |
| 5단(う단→え단) | 어미를 え단으로 변환 | 読(よ)む → 読(よ)め     | 읽어라   |
| 5단(う단→え단) | 어미를 え단으로 변환 | 走(はし)る → 走(はし)れ | 뛰어라   |
| 1단(る→ろ)     | る를 ろ로 변환       | 起(お)きる → 起(お)きろ | 일어나라 |
| 1단(る→ろ)     | る를 ろ로 변환       | 食(た)べる → 食(た)べろ | 먹어라   |
| 불규칙         | —                    | する → しろ             | 해라     |
| 불규칙         | —                    | 来(く)る → 来(こ)い     | 와라     |

**금지형 (～するな / ～하지 마)**

| 활용         | 만드는 법        | 예시                          | 의미    |
| ------------ | ---------------- | ----------------------------- | ------- |
| 전 그룹 공통 | 동사 사전형 + な | 忘(わす)れる → 忘(わす)れるな | 잊지 마 |
| 전 그룹 공통 | 동사 사전형 + な | 行(い)く → 行(い)くな         | 가지 마 |
| 전 그룹 공통 | 동사 사전형 + な | する → するな                 | 하지 마 |
| 전 그룹 공통 | 동사 사전형 + な | 来(く)る → 来(く)るな         | 오지 마 |

**부드러운 금지 (～しないで / ～하지 마)**

| 활용         | 만드는 법        | 예시                   | 의미               |
| ------------ | ---------------- | ---------------------- | ------------------ |
| 전 그룹 공통 | 동사 ない형 + で | 忘(わす)れないで       | 잊지 마 (부드럽게) |
| 전 그룹 공통 | 동사 ない형 + で | 心配(しんぱい)しないで | 걱정하지 마        |

**뉘앙스 비교**

| 표현               | 강도     | 뉘앙스           |
| ------------------ | -------- | ---------------- |
| 忘れるな           | 강함     | 강한 금지·명령   |
| 忘れるなよ         | 중강     | 친근한 경고·충고 |
| 忘れないで         | 부드러움 | 부탁·요청        |
| 忘れないでください | 정중     | 공손한 요청      |

```diff

```

- **문법**: 「眠すぎって」→「眠すぎて」。원인·이유를 나타낼 때는 「て」를 쓴다. 「って」는 인용(~라고)의 의미이므로 여기서는 맞지 않는다.

- **표현**: 문말에 「な」를 추가. "~군"의 감탄 뉘앙스를 살리기 위해 「な」를 붙인다.

> 眠い (ねむい) — 졸리다
> → 眠すぎる — 너무 졸리다 [+すぎる(과도)]
> → 眠すぎて — 너무 졸려서 [+て형]
>
> 死ぬ (しぬ) — 죽다
> → 死にそうだ — 죽을 것 같다 [+そうだ(추측)]
> → 死にそうだな — 죽겠군 [+감탄]
