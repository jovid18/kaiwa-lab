## 일본어

- 誰が寝た際にエアコンつけておいたか。

```diff
- 誰が寝た際にエアコンつけておいたか。
+ 誰が寝てる間にエアコンつけておいたの？
```

- **표현**: 「寝た際に」→「寝てる間に」。「際に」는 문어체/격식체 표현으로, 봄 아침에 추워서 투덜거리는 상황에 어울리지 않는다. 「寝てる間に」(자고 있는 동안에)가 일상 회화에서 자연스럽다. 또한 「寝た」(과거)보다 「寝てる」(진행)가 "자고 있는 동안"이라는 의미에 맞다.
- **표현**: 「か」→「の？」。문말의 「か」는 딱딱하고 사무적인 느낌이다. 일상적인 불만/의문에는 「の？」가 자연스럽다.

> 寝る (ねる) — 자다
> → 寝て — 자고 [て형]
> → 寝てる — 자고 있다 [+진행 (ている의 축약)]
>
> つける (つける) — 켜다
> → つけて — 켜고 [て형]
> → つけておいた — 켜놓았다 [+おく(방치/준비)+과거]

### Tip - 時・際・頃 구분

셋 다 "~할 때"로 번역되지만, 격식 수준과 의미 범위가 다르다.

| 표현     | 읽기      | 격식        | 의미                           | 예시                                                                       |
| -------- | --------- | ----------- | ------------------------------ | -------------------------------------------------------------------------- |
| 時(とき) | とき      | 일상~격식   | ~할 때 (가장 범용적)           | 寝てる**時**にエアコンつけた？ (자고 있을 때 에어컨 켰어?)                 |
| 際(さい) | さい      | 격식/문어체 | ~할 때, ~하는 경우 (공적 상황) | お帰りの**際**はお忘れ物のないように。 (돌아가실 때 소지품을 잊지 마세요.) |
| 頃(ころ) | ころ/ごろ | 일상~격식   | ~할 무렵, 대략적 시점          | 子供の**頃**はよく遊んだ。 (어린 시절에는 많이 놀았다.)                    |

**時 vs 際**

| 상황                      | 선택 | 이유              |
| ------------------------- | ---- | ----------------- |
| 일상 회화·독백·불만       | 時   | 자연스럽고 무난함 |
| 안내문·비즈니스·공식 발화 | 際   | 격식을 갖춘 느낌  |

**時 vs 頃**

| 상황                  | 선택 | 이유                                      |
| --------------------- | ---- | ----------------------------------------- |
| 특정 동작·조건과 동시 | 時   | 「寝てる時に」= 자고 있을 때 (동시성)     |
| 대략적 시기·시점      | 頃   | 「3時頃」= 3시쯤, 「学生の頃」= 학생 무렵 |

> 오늘 문장에서 「際に」를 썼지만, 투덜거리는 일상 회화이므로 「時に」 또는 「間に」가 적절하다. 「際」는 안내 방송이나 비즈니스 메일 같은 격식체에서 쓴다.

### Tip - 추측 표현 확신도별 정리

일본어에는 추측·예상을 나타내는 표현이 여러 가지 있으며, 화자의 확신도에 따라 구분된다.

| 표현         | 읽기         | 확신도 | 한글 뜻             | 접속                             | 예시                                          |
| ------------ | ------------ | ------ | ------------------- | -------------------------------- | --------------------------------------------- |
| はずだ       | はずだ       | ★★★★★  | ~일 것이다 (당연히) | 동사 보통형/な형+な/명사+の+はず | 届いたはずだ (도착했을 것이다)                |
| に違いない   | にちがいない | ★★★★☆  | ~에 틀림없다        | 보통형+に違いない                | 犯人に違いない (범인에 틀림없다)              |
| だろう       | だろう       | ★★★☆☆  | ~겠지, ~일 것이다   | 보통형+だろう                    | 海なら死ぬだろう (바다면 죽겠지)              |
| でしょう     | でしょう     | ★★★☆☆  | ~겠지요 (정중)      | 보통형+でしょう                  | 明日は雨でしょう (내일은 비겠지요)            |
| かもしれない | かもしれない | ★★☆☆☆  | ~일지도 모르다      | 보통형+かもしれない              | 間に合わないかもしれない (못 맞출지도 모른다) |

**だろう vs でしょう**

| 상황               | 선택     | 이유                                   |
| ------------------ | -------- | -------------------------------------- |
| 반말·독백·혼잣말   | だろう   | 친구·가족 간, 또는 자기 추측을 말할 때 |
| 존댓말·정중한 대화 | でしょう | 상대방에게 정중하게 추측을 전할 때     |
| 뉴스·일기예보      | でしょう | 공적 장면에서 추측을 전달할 때         |

**だろう의 파생 표현**

| 표현         | 의미                   | 예시                                          |
| ------------ | ---------------------- | --------------------------------------------- |
| だろうけど   | ~겠지만 (추측+역접)    | 海なら死ぬだろうけど (바다면 죽겠지만)        |
| だろうか     | ~일까? (자문·의문)     | 大丈夫だろうか (괜찮을까?)                    |
| だろうと思う | ~일 거라고 생각하다    | うまくいくだろうと思う (잘 될 거라 생각해)    |
| だろうに     | ~일 텐데 (아쉬움·유감) | 言えばよかっただろうに (말했으면 좋았을 텐데) |

> 한국어 "~겠지"는 대부분 「だろう」로 대응된다. 단, "~겠습니다"처럼 정중한 추측은 「でしょう」를 쓴다. 「かもしれない」는 확신이 낮을 때, 「はずだ」는 근거가 있어 확신이 높을 때 사용한다.

-　私どのようにこの話をするようになりますか？

```diff
- 私どのようにこの話をするようになりますか？

```

- **어휘**: 「私」→「私たち」。"저희"는 "우리"의 겸양어이므로 복수형 「私たち」를 쓴다. 「私」는 "나" 한 사람만 가리킨다.

- **문법**: 「するようになりますか」→「することになったんでしたっけ」。"하게 됐죠?"는 과거에 그렇게 된 경위를 확인하는 표현이다. 「なりますか」는 현재/미래형이므로 "하게 될까요?"가 된다. 「ことになった」(~하게 됐다) + 「んでしたっけ」(~였었죠?)로 과거 경위를 되묻는 뉘앙스를 살린다.

> する (する) — 하다
> → すること — 하는 것 [명사화]
> → することになった — 하게 됐다 [+ことになる(~게 되다)+과거]
> → することになったんでしたっけ — 하게 됐었죠? [+설명(んだ)+과거(でした)+확인(っけ)]

> かわいい (かわいい) — 예쁘다, 귀엽다

- 우연인것 같긴한데 겹친적이 없어서 신기하긴 하네요

## 일본어

-　偶然ようなだけど重なったことがなくて不思議ですね。

```diff
- 偶然ようなだけど重なったことがなくて不思議ですね。
+ 偶然だとは思うけど、重なったことがなくて不思議ではありますね。
```

- **문법**: 「偶然ようなだけど」→「偶然だとは思うけど」。"우연인것 같긴한데"는 "우연이라고 생각하긴 하지만"이라는 뜻이다. 「偶然ようなだ」는 문법적으로 성립하지 않는다(「よう」 앞에 「な」가 아닌 「の」가 와야 하며, 「偶然のようだ」가 되지만). "~같긴 한데"의 양보 뉘앙스를 살리려면 「偶然だとは思うけど」(우연이라고는 생각하지만)가 자연스럽다.
- **표현**: 「不思議ですね」→「不思議ではありますね」。"신기하긴 하네요"의 "~하긴 하다"는 인정하면서도 유보하는 뉘앙스다. 「ではありますね」로 "신기하기는 하네요"라는 인정의 뉘앙스를 살린다. 「ですね」만으로는 "신기하네요"로 단순 감상이 된다.

> 思う (おもう) — 생각하다
> → 思うけど — 생각하지만 [+역접 (けど)]
>
> 重なる (かさなる) — 겹치다
> → 重なった — 겹친 [과거]
> → 重なったことがない — 겹친 적이 없다 [+경험 부정 (ことがない)]
> → 重なったことがなくて — 겹친 적이 없어서 [+て형(이유)]
