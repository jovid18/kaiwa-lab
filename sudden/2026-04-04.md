## 일본어

> → 面倒な — 귀찮은 [な형용사 연체형]
> → 面倒なことだな — 귀찮은 일이군 [こと(것)+だ(이다)+な(감탄)]

> 気になる (きになる) — 궁금하다, 신경 쓰이다

>
> 合う (あう) — 맞다
> → 合っている — 맞고 있다 [て형+いる(상태)]

### Tip - もの・こと・の 구분

동사/형용사 뒤에 붙여 명사화할 때 もの・こと・の를 혼동하기 쉽다. 각각 가리키는 대상과 쓰이는 맥락이 다르다.

**기본 구분**

| 형식명사 | 핵심 의미        | 가리키는 대상         | 예문                 | 뜻                     |
| -------- | ---------------- | --------------------- | -------------------- | ---------------------- |
| こと     | 추상적 사실·행위 | 경험, 상황, 사실      | 復習することが大事だ | 복습하는 것이 중요하다 |
| もの     | 구체적 사물·본질 | 물건, 본래 성질       | 甘いものが好きだ     | 단 것을 좋아한다       |
| の       | 구어적 명사화    | こと/もの 대체 (구어) | 復習するのが大事だ   | 복습하는 게 중요하다   |

**こと를 쓰는 경우**

| 패턴                  | 예문                     | 뜻                    |
| --------------------- | ------------------------ | --------------------- |
| ~ことがある (경험)    | 日本に行ったことがある   | 일본에 간 적이 있다   |
| ~ことにする (결정)    | 早く寝ることにした       | 일찍 자기로 했다      |
| ~ことができる (가능)  | 日本語を話すことができる | 일본어를 말할 수 있다 |
| 사실·내용을 가리킬 때 | 面倒なことだな           | 귀찮은 일이군         |

**もの를 쓰는 경우**

| 패턴                    | 예문                 | 뜻                 |
| ----------------------- | -------------------- | ------------------ |
| 구체적 물건             | 食べるものがない     | 먹을 것이 없다     |
| ~ものだ (본래 그렇다)   | 人生はそういうものだ | 인생이란 그런 거다 |
| ~ものだから (이유·변명) | 急いでいたものだから | 급했기 때문에      |
| 감탄·회상               | よく遊んだものだ     | 참 많이 놀았지     |

**の를 쓰는 경우**

| 패턴                        | 예문                 | 뜻                    |
| --------------------------- | -------------------- | --------------------- |
| 구어에서 こと 대신          | 復習するのが一番いい | 복습하는 게 제일 좋다 |
| ~のに (역접)                | 言ったのに聞かない   | 말했는데 안 듣는다    |
| ~のは…だ (강조 구문)        | 驚いたのは値段だ     | 놀란 건 가격이다      |
| ~のが見える/聞こえる (지각) | 歌うのが聞こえた     | 노래하는 게 들렸다    |

> **주의**: もの 앞에 な형용사가 오면 반드시 「な」를 붙인다. ✕ 面倒もの → ○ 面倒なもの. こと도 마찬가지: ✕ 面倒こと → ○ 面倒なこと.

### Tip - ~때문에 (이유·원인 표현 구분)

"~때문에"에 해당하는 일본어 표현이 여러 개 있고, 뉘앙스와 뒤에 오는 결과의 성격이 다르다.

**핵심 구분**

| 표현              | 뉘앙스               | 결과           | 예문                   | 뜻                            |
| ----------------- | -------------------- | -------------- | ---------------------- | ----------------------------- |
| から              | 주관적 이유 (구어적) | 긍정/부정 모두 | 急いでいたから忘れた   | 급해서 잊었다                 |
| ので              | 객관적 이유 (정중)   | 긍정/부정 모두 | 雨なので中止します     | 비라서 중지합니다             |
| せいで            | 부정적 원인 (탓)     | 나쁜 결과만    | 風邪のせいで休んだ     | 감기 탓에 쉬었다              |
| おかげで          | 긍정적 원인 (덕분)   | 좋은 결과만    | 先生のおかげで受かった | 선생님 덕분에 합격했다        |
| ために            | 원인 (객관·서면)     | 긍정/부정 모두 | 事故のために遅れた     | 사고 때문에 늦었다            |
| もので/ものだから | 변명·해명            | 어쩔 수 없었다 | 初めてだったもので     | 처음이었기 때문에 (양해 구함) |

**접속 방법**

| 표현     | 동사           | い형용사   | な형용사     | 명사           |
| -------- | -------------- | ---------- | ------------ | -------------- |
| から     | 食べたから     | 高いから   | 静かだから   | 学生だから     |
| ので     | 食べたので     | 高いので   | 静かなので   | 学生なので     |
| せいで   | 食べたせいで   | 高いせいで | 静かなせいで | 学生のせいで   |
| おかげで | 食べたおかげで | —          | —            | 先生のおかげで |
| ために   | 食べたために   | —          | 静かなために | 事故のために   |

**사용 판단 기준**

| 상황               | 추천 표현 | 예문                                       | 뜻                                     |
| ------------------ | --------- | ------------------------------------------ | -------------------------------------- |
| 일상 회화, 반말    | から      | 肉食べたから、似たようなのは避けたい       | 고기 먹었으니까 비슷한 건 피하고 싶어  |
| 정중한 설명        | ので      | 時間がかかりすぎているので削除してください | 시간이 너무 걸리고 있어서 삭제해주세요 |
| 남 탓, 부정적 원인 | せいで    | 関連パートのせいで時間がかかっている       | 관련 파트 때문에 시간이 걸리고 있어    |
| 감사, 긍정적 원인  | おかげで  | あなたのおかげで助かった                   | 네 덕분에 살았다                       |
| 변명·양해          | もので    | 慣れていないもので、すみません             | 익숙하지 않아서요, 죄송합니다          |

> **주의**: 「せいで」를 상대방에게 직접 쓰면 비난이 된다. 「あなたのせいで」= "네 탓이야". 반대로 「おかげで」를 부정적 결과에 쓰면 비꼬는 표현이 된다. 「おかげで遅刻した」= "덕분에 지각했다(빈정거림)".

### Tip - 어휘&표현: 행동

일상생활에서 자주 쓰는 행동 표현. 「~をかける」처럼 하나의 동사가 여러 의미로 쓰이는 경우에 주의.

**식사·위생**

| 일본어           | 발음             | 한글 뜻     |
| ---------------- | ---------------- | ----------- |
| ご飯を食べる     | ごはんをたべる   | 밥을 먹다   |
| 顔を洗う         | かおをあらう     | 세수를 하다 |
| 歯を磨く         | はをみがく       | 이를 닦다   |
| シャワーを浴びる | シャワーをあびる | 샤워를 하다 |
| 化粧をする       | けしょうをする   | 화장을 하다 |

**가사**

| 일본어           | 발음                 | 한글 뜻         |
| ---------------- | -------------------- | --------------- |
| 後片付けをする   | あとかたづけをする   | 뒷정리를 하다   |
| 掃除機をかける   | そうじきをかける     | 청소기를 돌리다 |
| 洗濯物を干す     | せんたくものをほす   | 빨래를 널다     |
| 洗濯物をしまう   | せんたくものをしまう | 빨래를 걷다     |
| アイロンをかける | アイロンをかける     | 다림질을 하다   |
| 布団を畳む       | ふとんをたたむ       | 이불을 개다     |

**기타 행동**

| 일본어       | 발음           | 한글 뜻       |
| ------------ | -------------- | ------------- |
| 歌を歌う     | うたをうたう   | 노래를 부르다 |
| 音楽を聞く   | おんがくをきく | 음악을 듣다   |
| 踊りを踊る   | おどりをおどる | 춤을 추다     |
| ぐうぐう寝る | ぐうぐうねる   | 쿨쿨 자다     |
| いびきをかく | いびきをかく   | 코를 골다     |
| 汗をかく     | あせをかく     | 땀을 흘리다   |
| 汗を拭く     | あせをふく     | 땀을 닦다     |
| 傘を差す     | かさをさす     | 우산을 쓰다   |
| 傘を開く     | かさをひらく   | 우산을 펴다   |
| 傘を畳む     | かさをたたむ   | 우산을 접다   |

> **かける의 다의어**: 「掃除機をかける」(청소기를 돌리다), 「アイロンをかける」(다림질을 하다)처럼 「かける」는 도구를 작동시키는 의미로 폭넓게 쓰인다. 「鍵をかける」(잠그다), 「電話をかける」(전화하다) 등도 함께 기억해두면 좋다.
>
> **かく의 다의어**: 「汗をかく」(땀을 흘리다), 「いびきをかく」(코를 골다), 「頭を掻く」(머리를 긁다) — 같은 발음이지만 한자가 다르다. 汗を**かく**(한자 없음), いびきを**かく**(한자 없음), 頭を**掻く**(긁다).
