> 遅れる (おくれる) — 늦다
> → 遅れそうだ — 늦을 것 같다 [추측]

### 종조사「な」(감탄) 접속 규칙

문장 끝에서 혼잣말·감탄을 나타내는「な」는 **종지형(문장을 끝맺는 형태)** 뒤에 붙는다.

| 품사     | 종지형 + な      | 연체형 + 명사    | 비고                                     |
| -------- | ---------------- | ---------------- | ---------------------------------------- |
| 동사     | 行くな           | 行く人           | 동사는 종지형=연체형이라 헷갈리지 않음   |
| い형용사 | 寒いな           | 寒い日           | 마찬가지로 형태 동일                     |
| な형용사 | 静か**だ**な     | 静か**な**部屋   | **だ**(종지형) vs **な**(연체형) — 주의! |
| 명사+だ  | 雨**だ**な       | 雨**の**日       | 명사도 だ가 필요                         |
| 〜そうだ | 遅れそう**だ**な | 遅れそう**な**顔 | 이번 문장의 케이스                       |

- 「そうな」「静かな」「きれいな」처럼 **な**로 끝나면 → 뒤에 명사가 와야 하는 연체형
- 감탄의「な」를 붙이려면 → 반드시 **だ**な 형태로

## 일본어

- それは私も招待してくれたら午後に参加します。

```diff
- それは私も招待してくれたら午後に参加します。
+ それでしたら私も招待していただければ午後に参加いたします。
```

- **어휘**: 「それは」→「それでしたら」。「그러면」은 조건·전환의 접속이므로「それでしたら」가 자연스럽다.「それは」는 「그것은」의 의미.
- **표현**: 「くれたら」→「いただければ」。「해주시면」은 상대의 행위에 대한 존경 표현이므로「くれる」(반말)가 아니라「いただく」(겸양어)를 쓴다.
- **표현**: 「参加します」→「参加いたします」。앞에서 겸양어를 썼으므로 문체 통일을 위해「いたします」로 맞춘다.

> 招待する (しょうたいする) — 초대하다
> → 招待していただく — 초대해주시다 [て형+겸양]
> → 招待していただければ — 초대해주시면 [+ば형(조건)]
>
> 参加する (さんかする) — 참가하다
> → 参加いたす — 참가하다 (겸양) [겸양]
> → 参加いたします — 참가하겠습니다 [+경어]

### 「てくれる」 vs 「てもらう」 경어 변환

「~해주다」를 경어로 올리는 두 가지 경로:

| 단계 | 존경어 (상대를 높임) | 겸양어 (나를 낮춤) |
| ---- | -------------------- | ------------------ |
| 원형 | てくれる             | てもらう           |
| 경어 | て**くださる**       | て**いただく**     |
| 시점 | 상대가 해**주시다**  | 내가 **받다**      |

- **존경어**: 招待して**くだされば** — 초대해주시면 (상대의 행위를 높임)
- **겸양어**: 招待して**いただければ** — 초대해주시면 (내가 받는 쪽임을 낮춤)

둘 다 「해주시면」으로 번역되지만, 비즈니스에서는 **いただく**(겸양) 쪽이 더 자주 쓰인다. 자기를 낮추는 것이 더 공손하게 느껴지기 때문.

## 일본어

- 今朝に３７個のエージェントをオーケストレーションして１０億ダーラー会社を建てる人があったがお前はただ朝ご飯を食べっていた。

```diff
- 今朝に３７個のエージェントをオーケストレーションして１０億ダーラー会社を建てる人があったがお前はただ朝ご飯を食べっていた。
+ 今朝37個のエージェントをオーケストレーションして10億ドルの会社を作った人がいたのに、お前はただ朝ご飯でも食べていた。
```

- **문법**: 「今朝に」→「今朝」。「今朝」는 그 자체로 부사이므로 조사「に」를 붙이지 않는다. (cf. 「昨日」「今日」도 마찬가지)
- **어휘**: 「ダーラー」→「ドル」。달러의 일본어 표기는「ドル」.
- **문법**: 「ダーラー会社」→「ドルの会社」。명사를 수식할 때 연결 조사「の」가 필요하다.
- **어휘**: 「建てる」→「作った」。「建てる」는 건물을 짓다.「회사를 만들다」는「作る」를 쓴다. 또한「만든(과거)」이므로 과거형「作った」.
- **문법**: 「人があった」→「人がいた」。사람의 존재에는「いる」를 쓴다.「ある」는 무생물 전용.
- **문법**: 「あったが」→「いたのに」。「있는데(그런데 넌~)」의 비난·대조 뉘앙스는「のに」가 자연스럽다.「が」는 단순 접속.
- **문법**: 「食べっていた」→「食べていた」。「食べる」는 1단 동사로 て형은「食べて」. 촉음「っ」이 들어가지 않는다.
- **표현**: 「朝ご飯を」→「朝ご飯でも」。「아침이나」의「이나」는 가볍게 비하하는 뉘앙스로, 일본어에서는「でも」가 대응한다.

> 作る (つくる) — 만들다
> → 作った — 만들었다 [과거]
>
> いる — 있다 (생물)
> → いた — 있었다 [과거]
>
> 食べる (たべる) — 먹다
> → 食べて — 먹고 [て형]
> → 食べていた — 먹고 있었다 [+과거]

### 한국어「이나/나」와 일본어「でも」

「이나」는 "그것밖에 안 하고 있었다"는 가벼운 비하·한정의 뉘앙스. 일본어에서는「でも」가 대응한다.

| 한국어               | 일본어                   | 뉘앙스                        |
| -------------------- | ------------------------ | ----------------------------- |
| 커피나 마시자        | コーヒー**でも**飲もう   | 뭐 딱히 ~이라도 (가벼운 제안) |
| 아침이나 먹고 있었다 | 朝ご飯**でも**食べていた | 고작 ~이나 (비하·한심)        |
| 게임이나 하고 있어   | ゲーム**でも**してろ     | ~이나 하고 있어라 (무시)      |
| 영화나 볼까          | 映画**でも**観ようか     | ~이라도 볼까 (가벼운 선택)    |

- 「を」를 쓰면 단순히 "~을/를" (객관적 서술)
- 「でも」를 쓰면 "~이나/~이라도" (대충, 별것 아닌, 그나마)

### 「ないで」— 부정의 て형

「ない」에「で」를 붙인 형태로, 두 가지 용법이 있다.

#### 1. 부탁·금지: 「~하지 마(줘)」

| 표현           | 뉘앙스           | 예문                 |
| -------------- | ---------------- | -------------------- |
| ないで         | 부드러운 부탁    | 行かないで (가지 마) |
| ないでください | 정중한 부탁      | 行かないでください   |
| ないでくれ     | 반말 부탁 (남성) | 行かないでくれ       |

- 「行かないで」단독으로 쓰면 감정이 실린 부드러운 부탁·애원의 뉘앙스.

#### 2. 부정 상태로 ~하다: 「~하지 않고」

동작의 부정 상태를 유지한 채 다른 동작을 할 때도 쓴다.

| 일본어                     | 한국어                  |
| -------------------------- | ----------------------- |
| 朝ご飯を食べないで出かけた | 아침을 안 먹고 나갔다   |
| 傘を持たないで来た         | 우산을 안 가져오고 왔다 |

- 이 경우「ないで」≒「なくて」이지만,「ないで」는 의도적 선택의 뉘앙스가 더 강하다.
