## 일본어

-　どうやって会話こんなにすぐに変えるんでしょ？

```diff
- どうやって会話こんなにすぐに変えるんでしょ？
+ どうして会話がこんなにコロコロ変わるんでしょう？
```

- **문법**: 「会話」→「会話が」。주어에는 조사 「が」가 필요.
- **문법**: 「変える」→「変わる」。"바뀌다"는 자동사이므로 「変わる」가 맞음. 「変える」는 타동사 "바꾸다".
- **어휘**: 「すぐに」→「コロコロ」。"금방금방"은 반복적으로 자주 바뀌는 느낌. 「コロコロ」가 이 뉘앙스를 살림.
- **표현**: 「どうやって」→「どうして」。방법이 아닌 놀라움을 표현하므로 「どうして」가 자연스러움.

> 変わる (かわる) — 바뀌다
> → 変わるん — 바뀌는 건 [설명(ん)]
> → 変わるんでしょう — 바뀌는 건가요 [+추측]

## 일본어

```diff

```

- **어휘**: 「単に」→「もう」。"그냥"은 여기서 "에라 모르겠다"는 느낌. 「単に」(단순히)는 의미가 다름.

> 夜更かしする (よふかしする) — 밤늦게까지 깨어 있다
> → 夜更かししちゃう — 밤늦게까지 깨어 있어 버리다 [てしまう(구어)]
> → 夜更かししちゃおう — 밤늦게까지 깨어 있어 버리자 [+의지]

### Tip - ことにする vs ことになる

둘 다 「〜ことに」로 시작하지만, する(자기 의지)와 なる(자연스러운 결과)로 주체가 다르다.

**ことにする — ~하기로 하다 (자기 결정)**

| 문형             | 의미                     | 예시                                                         |
| ---------------- | ------------------------ | ------------------------------------------------------------ |
| 〜ことにする     | ~하기로 하다             | 毎日走ることにする。(매일 달리기로 하다)                     |
| 〜ことにした     | ~하기로 했다             | 転職することにした。(이직하기로 했다)                        |
| 〜ないことにする | ~하지 않기로 하다        | 今日は飲まないことにする。(오늘은 안 마시기로 하다)          |
| 〜ことにしている | ~하기로 하고 있다 (습관) | 朝早く起きることにしている。(아침 일찍 일어나기로 하고 있다) |

**ことになる — ~하게 되다 (외부 결정·자연스러운 결과)**

| 문형               | 의미                        | 예시                                                                   |
| ------------------ | --------------------------- | ---------------------------------------------------------------------- |
| 〜ことになる       | ~하게 되다                  | 来月から大阪に転勤することになる。(다음 달부터 오사카로 전근가게 되다) |
| 〜ことになった     | ~하게 되었다                | 日本に留学することになった。(일본에 유학가게 되었다)                   |
| 〜ないことになった | ~하지 않게 되었다           | 出張に行かないことになった。(출장 안 가게 되었다)                      |
| 〜ことになっている | ~하게 되어 있다 (규칙·예정) | 社員は制服を着ることになっている。(사원은 제복을 입게 되어 있다)       |

> 핵심: 본인이 결정했으면 「ことにする」, 상황이나 외부 요인으로 그렇게 되었으면 「ことになる」. 본문의 "하게 되네요"는 자연스럽게 그렇게 된 것이므로 「ことになる」를 사용.

### Tip - 気になる vs 気にする

둘 다 「気」를 사용하지만, なる(자연스럽게 그렇게 되다)와 する(의식적으로 그렇게 하다)로 주체의 의지가 다르다.

**気になる — 궁금하다·신경 쓰이다 (자연스러운 감정)**

저절로 마음에 걸리거나 궁금해지는 상태. 본인의 의지와 상관없이 신경이 쓰인다.

| 문형           | 의미              | 예시                                              |
| -------------- | ----------------- | ------------------------------------------------- |
| 気になる       | 궁금하다          | あの映画が気になる。(그 영화가 궁금하다)          |
| 気になっていた | 궁금했었다        | ずっと気になっていた。(계속 궁금했었다)           |
| 気になってた   | 궁금했었다 (구어) | インタビューは気になってた。(인터뷰는 궁금했었다) |
| 気にならない   | 신경 쓰이지 않다  | 全然気にならない。(전혀 신경 쓰이지 않다)         |

**気にする — 신경 쓰다·걱정하다 (의식적 행위)**

본인이 의식적으로 신경을 쓰거나 걱정하는 행위. 주로 부정형·명령형으로 "신경 쓰지 마"라는 표현에 많이 쓴다.

| 문형         | 의미           | 예시                                             |
| ------------ | -------------- | ------------------------------------------------ |
| 気にする     | 신경 쓰다      | 細かいことを気にする。(사소한 것을 신경 쓰다)    |
| 気にしないで | 신경 쓰지 마   | そんなこと気にしないで。(그런 거 신경 쓰지 마)   |
| 気にしすぎ   | 너무 신경 씀   | 気にしすぎだよ。(너무 신경 쓰는 거야)            |
| 気にしている | 신경 쓰고 있다 | 彼はまだ気にしている。(그는 아직 신경 쓰고 있다) |

> 핵심: "궁금하다"는 「気になる」, "신경 쓰다·걱정하다"는 「気にする」. 본문의 "궁금했었는데"는 자연스럽게 궁금해진 것이므로 「気になってた」이 맞고, 「気にする」는 의미가 다르다.
