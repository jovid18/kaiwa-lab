## Part 2

## Question

- 731-0582이 전화번호
- 店の電話番号は何番ですか。

## Answer

- 연습을 위해 일본어는 숫자로 적지 않는다
- 가게의 전화번호는 731-0582 입니다.
- 店の電話番号はななさんいちれいごはちにです。

## Feedback

```diff
- 店の電話番号はななさんいちれいごはちにです。
+ 店の電話番号はななさんいちの、ぜろごはちにです。
```

- **표현**: 전화번호를 읽을 때 하이픈(`-`) 위치에서 「の」를 넣어 구분하는 것이 일반적이다. 「ななさんいち**の**ぜろごはちに」처럼 끊어 읽어야 자연스럽다.
- **어휘**: 전화번호에서 0은 「れい」보다 「ゼロ」 또는 「まる」를 쓰는 것이 일반적이다. 「れい」는 숫자를 읽을 때(수량, 점수 등)에 쓰고, 전화번호·방 번호 등 번호를 나열할 때는 「ゼロ」나 「まる」가 자연스럽다.
- **SJPT**: Part 2는 준비 3초, 응답 6초로 짧다. 전화번호 문제는 정확한 발음과 끊어 읽기가 핵심이므로, 「の」로 구분하여 또박또박 읽는 연습이 중요하다.

## Part 2

## Question

- 축구공이 3개 농구공이 5개
- どちらの方が少ないですか。

## Answer

- 축구공이 농구공보다 2개 더 적습니다.
- サッカーボールがバスケットボールより二つ少ないです。

## Feedback

```diff
- サッカーボールがバスケットボールより二つ少ないです。
+ サッカーボールの方がバスケットボールより二個少ないです。
```

- **문법**: 「どちらの方が」로 물었으므로, 답변에도 「の方が」를 넣어 대응시키는 것이 자연스럽다. 「サッカーボール**の方が**」로 "축구공 쪽이"라는 비교 주어를 명확히 한다.
- **어휘**: 공처럼 개별 물건을 셀 때는 「つ」보다 「個(こ)」가 더 정확한 조수사이다. 「つ」는 범용이지만, 구체적인 물건의 수량 차이를 말할 때 「個」가 자연스럽다.
- **SJPT**: Part 2는 6초 응답이므로, 질문의 핵심(どちらの方が)에 맞춰 「～の方が」로 답하는 패턴을 습관화하면 빠르고 정확하게 대응할 수 있다.

### Tip - 個(こ) vs つ 조수사 비교

「個」는 음독 계열, 「つ」는 훈독 계열 조수사이다. 「個」는 구체적인 물건을 셀 때, 「つ」는 범용적으로 쓴다.

| 개수 | 個 (음독) | つ (훈독) |
| ---- | --------- | --------- |
| 1    | いっこ    | ひとつ    |
| 2    | にこ      | ふたつ    |
| 3    | さんこ    | みっつ    |
| 4    | よんこ    | よっつ    |
| 5    | ごこ      | いつつ    |
| 6    | ろっこ    | むっつ    |
| 7    | ななこ    | ななつ    |
| 8    | はっこ    | やっつ    |
| 9    | きゅうこ  | ここのつ  |
| 10   | じゅっこ  | とお      |

> 「個」는 1·6·8·10에서 촉음(っ)이 들어간다 (いっこ、ろっこ、はっこ、じゅっこ). 「つ」는 10만 「とお」로 특수하다. 11 이상은 「つ」를 쓸 수 없으므로 「個」를 사용한다.

## Question

- 컴퓨터가 책상위에 있음
- パソコンはどこにありますか。

## Answer

- 컴퓨터는 책상위에 있습니다.
- パソコンは机の上にあります。

## Feedback

- **SJPT**: Part 2 「どこにありますか」 질문에 「～の上にあります」로 답하는 패턴은 위치 묘사의 기본형이다. 6초 내에 즉답하려면 「上(うえ)·下(した)·中(なか)·横(よこ)·前(まえ)·後ろ(うしろ)」 + 「にあります」를 반사적으로 나올 수 있도록 연습해두면 좋다.

- 男の人は午後3時に何をしましたか。

- 男の人は午後3時に女の人の写真を撮りました。

## Feedback

- **SJPT**: Part 2는 6초 응답이므로, 「何をしましたか」에 대해 질문의 주어·시간을 그대로 받아 「～を撮りました」로 답하는 패턴이 효율적이다. 그림에서 동작을 빠르게 파악하여 동사를 떠올리는 연습이 핵심이다.

### Tip - 시간 표현 (시·분·때를 나타내는 말)

시간을 읽을 때 특수한 발음이 되는 숫자가 있으므로 주의한다.

**시 (時)**

| 시간 | 발음     | 시간 | 발음       | 시간 | 발음         |
| ---- | -------- | ---- | ---------- | ---- | ------------ |
| 1時  | いちじ   | 6時  | ろくじ     | 11時 | じゅういちじ |
| 2時  | にじ     | 7時  | **しちじ** | 12時 | じゅうにじ   |
| 3時  | さんじ   | 8時  | はちじ     | 何時 | なんじ       |
| 4時  | **よじ** | 9時  | **くじ**   |      |              |
| 5時  | ごじ     | 10時 | じゅうじ   |      |              |

> 4時는 「よじ」(よんじ ✕), 7時는 「しちじ」(ななじ ✕), 9時는 「くじ」(きゅうじ ✕)로 읽는다. 12시간제로 「午前(ごぜん)」「午後(ごご)」를 붙이거나, 24시간제로 「13時」처럼 표현할 수도 있다.

**분 (分)**

| 분  | 발음                   | 분   | 발음                         |
| --- | ---------------------- | ---- | ---------------------------- |
| 1分 | い**っぷん**           | 10分 | じゅ**っぷん**               |
| 2分 | にふん                 | 20分 | にじゅ**っぷん**             |
| 3分 | **さんぷん**           | 30分 | さんじゅ**っぷん**・半(はん) |
| 4分 | よん**ぷん**           | 40分 | よんじゅ**っぷん**           |
| 5分 | ごふん                 | 50分 | ごじゅ**っぷん**             |
| 6分 | ろ**っぷん**           | 60分 | ろくじゅ**っぷん**           |
| 7分 | ななふん・しちふん     | 何分 | **なんぷん**                 |
| 8分 | は**っぷん**・はちふん |      |                              |
| 9分 | きゅうふん             |      |                              |

> 10분 단위의 「分」은 「じゅっぷん」 또는 「じっぷん」으로 읽는다. 30分은 「半(はん)」으로도 표현 가능.
