## Part 3

## Question

- 내일부터 백화점에서 세일이 시작되는 것 같아요

## Answer

- 오 그렇군요, 마침 예전에 샀던 믹서기가 잘 안되고 있었는데, 이참에 새로 하나 사러가야겠네요.
- お、そうですか、ちょうど以前に買ったミキサーがうまく行っていなくて、この時新しく一つ買おうと思います。。
- お、そうですか。ちょうど前に買ったミキサーの調子が悪くなっていたので、この機会に新しいのを一つ買いに行かなきゃですね。

### diff

```diff
- お、そうですか、ちょうど以前に買ったミキサーがうまく行っていなくて、この時新しく一つ買おうと思います。。
+ お、そうですか。ちょうど前に買ったミキサーの調子が悪くなっていたので、この機会に新しいのを一つ買いに行かなきゃですね。
```

### 코멘트

1. **うまく行っていなくて → 調子が悪くなっていたので**
   - 「うまくいく」는 "일이 잘 풀리다"라는 뜻으로 기계 고장에는 부자연스러움
   - 기기가 잘 안 되는 상황에는 「調子が悪い」가 자연스러움
   - 「~는데」(배경 설명 + 후속 행동 연결)는 「~ので」가 적합

2. **この時 → この機会に**
   - 「この時」는 "이 시점"이라는 시간적 의미가 강함
   - "이참에" = 기회를 잡아서 → 「この機会に」 또는 「この際」

3. **買おうと思います → 買いに行かなきゃですね**
   - "사러가야겠네요"에는 이동(사러 **가다**)이 포함됨 → 「買いに行く」
   - "~야겠네요"는 깨달음 + 가벼운 의무감 → 「~なきゃですね」가 뉘앙스에 맞음
   - 「買おうと思います」는 딱딱하고 "~려고 합니다" 느낌

4. **以前 → 前**
   - 일상 회화에서는 「前に」가 더 자연스러움

## Part 3

## Question

- 이번 주 토요일에 같이 등산하러 가지 않을래요?

## Answer

- 오, 제안해주셔서 감사합니다. 몇시에 만나실까요? 등산하기 전에 가게에서 김밥도 하나 사갈까요?
- お、誘ってくれてありがたいですね。何時に会いましょうか？登山する前いに店でキンパも一つ買いますか？。
- お、誘ってくださってありがとうございます。何時に会いましょうか？登山する前にお店でキンパも一つ買っていきましょうか？

### diff

```diff
- お、誘ってくれてありがたいですね。何時に会いましょうか？登山する前いに店でキンパも一つ買いますか？。
+ お、誘ってくださってありがとうございます。何時に会いましょうか？登山する前にお店でキンパも一つ買っていきましょうか？
```

### 코멘트

1. **誘ってくれて → 誘ってくださって**
   - 전체적으로 경어체(ましょうか)를 쓰고 있으므로 「くださる」로 통일해야 자연스러움

2. **ありがたいですね → ありがとうございます**
   - 「ありがたい」는 "고맙다"는 형용사이고, 감사 인사에는 「ありがとうございます」를 사용
   - 「ね」도 감사 표현에는 부적절 (상대에게 동의를 구하는 뉘앙스)

3. **前いに → 前に**
   - 「い」가 불필요한 오타

4. **買いますか → 買っていきましょうか**
   - "사갈까요"에는 이동의 의미("사서 가지고 가다")가 포함되어 「買っていく」가 필요
   - "~ㄹ까요?"는 제안이므로 「ましょうか」가 적합. 「買いますか」는 "사나요?"라는 단순 질문
