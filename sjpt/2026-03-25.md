## Question

- 상자 안에 희고 둥근 접시가 있음
- 상자 안에는 무엇이 들어 있습니까?

## Answer

- 상자안에는 하얗고 동그란 접시가 들어가 있습니다.
- 箱の中には白く丸い皿が入っています。

## Feedback

```diff
- 箱の中には白く丸い皿が入っています。
+ 箱の中には白くて丸いお皿が入っています。
```

- **문법**: い형용사를 나열할 때 구어에서는 「白くて丸い」처럼 て형으로 연결하는 것이 자연스럽다. 「白く丸い」는 문어적 연용형 접속으로, SJPT 말하기 시험에서는 「白くて」가 적절하다.
- **어휘**: 「皿」보다 「お皿」가 구어에서 더 자연스럽다. 접두어 「お」를 붙이는 것이 일상 회화의 일반적인 표현이다.

### Tip - 「入」의 읽기 구분 (はいる/いる/いれる)

「入」는 자동사·타동사에 따라 읽기가 달라진다. 핵심은 **자동사 = はいる, 타동사 = いれる**이고, 복합어에서는 「いる/いり」로 읽는 경우가 많다.

**자동사: 入る(はいる) — 들어가다**

| 표현       | 발음         | 한글 뜻   | 예시                              |
| ---------- | ------------ | --------- | --------------------------------- |
| 入る       | はいる       | 들어가다  | お風呂に入る (목욕하다)           |
| 入っている | はいっている | 들어 있다 | 箱に入っている (상자에 들어 있다) |

**타동사: 入れる(いれる) — 넣다**

| 표현       | 발음       | 한글 뜻        | 예시                                |
| ---------- | ---------- | -------------- | ----------------------------------- |
| 入れる     | いれる     | 넣다           | かばんに入れる (가방에 넣다)        |
| 入れている | いれている | 넣어 두고 있다 | 砂糖を入れている (설탕을 넣고 있다) |

**복합어: いる/いり로 읽는 경우**

| 표현       | 발음       | 한글 뜻             |
| ---------- | ---------- | ------------------- |
| 入口       | いりぐち   | 입구                |
| 入り込む   | はいりこむ | 파고들다            |
| 気に入る   | きにいる   | 마음에 들다         |
| 手に入れる | てにいれる | 손에 넣다, 입수하다 |
| 記入       | きにゅう   | 기입                |

> 오늘 문장의 「入っています」는 자동사 「入る(はいる)」의 ている형이므로 **はいっています**로 읽는다.

## Question

- 버스 정거장에서 한명은 앉아있고 두명은 서있음
- 앉아 있는 사람은 몇명입니까?

## Answer

- 앉아 있는 사람은 남자 한명입니다.
- 座っている人は男の一人です。

## Feedback

```diff
- 座っている人は男の一人です。
+ 座っている人は男の人が一人です。
+ 座っている人は男性が一人です。
```

- **문법**: 「男の一人」은 "남자들 중 한 명"이라는 뜻이 되어 의미가 달라진다. "남자 한 명"이라고 수를 답할 때는 「男の人が一人です」처럼 「が + 수량사」 구조를 사용한다. 「男性(だんせい)が一人です」도 자연스럽다.
