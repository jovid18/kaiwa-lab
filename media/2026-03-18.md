### expression

- あなたじゃ話にならん平凡 — 너 따위는 상대도 안 되는 평범함

> なる (なる) — 되다
> → ならん — 되지 않는다 [부정 (ならぬ의 구어 축약)]

### Tip - ぬ/ん (문어체 부정)

「ない」의 고어(古語) 부정형. 현대 일본어에서도 격식체·관용 표현·노래 가사 등에서 자주 쓰인다.

**변환 규칙**

| 현대 부정 (ない) | 문어 부정 (ぬ) | 구어 축약 (ん) | 의미        |
| ---------------- | -------------- | -------------- | ----------- |
| ならない         | ならぬ         | ならん         | 되지 않는다 |
| 知らない         | 知らぬ         | 知らん         | 모른다      |
| できない         | できぬ         | できん         | 할 수 없다  |
| わからない       | わからぬ       | わからん       | 모르겠다    |

**자주 쓰는 관용 표현**

| 표현           | 뜻                   | 예시                                 |
| -------------- | -------------------- | ------------------------------------ |
| ~てはならぬ/ん | ~해서는 안 된다      | 逃げてはならん (도망쳐서는 안 된다)  |
| ~ねばならぬ/ん | ~하지 않으면 안 된다 | 行かねばならん (가지 않으면 안 된다) |
| ~ぬうちに      | ~하기 전에           | 忘れぬうちに (잊기 전에)             |

> 「ぬ」는 딱딱하고 단호한 어감, 「ん」은 거기에 구어적 가벼움이 더해진다. 가사·만화·시대극에서 특히 자주 등장.

- 弱音吐いて悶えたって無駄で無駄で愚かさすら気付けないよね — 약한 소리 내뱉고 몸부림쳐봤자 헛수고에 헛수고, 어리석음조차 알아차리지 못하잖아

> 吐く (はく) — 뱉다, 내뱉다
> → 吐いて — 내뱉고 [て형]
>
> 悶える (もだえる) — 몸부림치다
> → 悶えた — 몸부림쳤다 [과거]
> → 悶えたって — 몸부림쳐봤자 [+たって (역접/양보)]
>
> 気付く (きづく) — 알아차리다
> → 気付ける — 알아차릴 수 있다 [가능]
> → 気付けない — 알아차릴 수 없다 [+부정]

- 逃げちゃダメ枯れちゃダメ — 도망치면 안 돼 시들면 안 돼

> 逃げる (にげる) — 도망치다
> → 逃げちゃ — 도망치면 [て형+しまう의 축약 (ちゃ=ては)]
>
> 枯れる (かれる) — 시들다
> → 枯れちゃ — 시들면 [て형+しまう의 축약 (ちゃ=ては)]

### Tip - すら (조차, ~마저)

「すら」는 "~조차, ~마저"를 뜻하는 부조사로, 극단적인 예를 들어 강조할 때 쓴다. 비슷한 표현인 「さえ」「も」와 비교하면 문어적·강조적 뉘앙스가 가장 강하다.

**기본 구조**: 명사 + すら / 동사て형 + すら

| 표현 | 뉘앙스                    | 격식      | 예시                                              |
| ---- | ------------------------- | --------- | ------------------------------------------------- |
| すら | ~조차 (극단 강조, 문어적) | 문어~격식 | 名前(なまえ)すら知(し)らない。 (이름조차 모른다.) |
| さえ | ~조차, ~마저 (범용)       | 일상~격식 | 名前さえ知らない。 (이름조차 모른다.)             |
| も   | ~도 (가벼운 포함)         | 일상      | 名前も知らない。 (이름도 모른다.)                 |
