### expression

- 田淵くん入れなくなっちゃってさ — 타부치 군이 들어갈 수 없게 돼버려서

> 入る (はいる) — 들어가다
> → 入れる — 들어갈 수 있다 [가능]
> → 入れない — 들어갈 수 없다 [+부정]
> → 入れなくなる — 들어갈 수 없게 되다 [+なくなる]
> → 入れなくなっちゃう — 들어갈 수 없게 돼버리다 [+ちゃう(てしまう 구어)]
> → 入れなくなっちゃって — 들어갈 수 없게 돼버려서 [+て형]

- いやそんなずっと外にいるわけじゃないから — 아니 그렇게 계속 밖에 있는 건 아니니까

- あの付け根のネジが外れちゃったんですけど — 저 밑동의 나사가 빠져버렸는데요

> 外れる (はずれる) — 빠지다, 벗어나다
> → 外れちゃう — 빠져버리다 [ちゃう(てしまう 구어)]
> → 外れちゃった — 빠져버렸다 [+과거]

- いそうなのに — 있을 것 같은데

> いる — 있다

> → いそうな — 있을 것 같은 [+연체형]
> → いそうなのに — 있을 것 같은데 [+のに(역접)]

### Tip - ふり(~인 척하다)

「ふり」는 실제로는 그렇지 않은데 겉으로 그런 것처럼 행동할 때 사용한다. 접속 형태에 따라 동사·형용사·명사 모두 붙을 수 있다.

**접속 규칙**

| 품사     | 접속 형태                | 예시               | 의미          |
| -------- | ------------------------ | ------------------ | ------------- |
| 동사     | 동사 보통형 + ふりをする | 知らないふりをする | 모르는 척하다 |
| い형용사 | い형 + ふりをする        | 楽しいふりをする   | 즐거운 척하다 |
| な형용사 | 語幹 + な + ふりをする   | 元気なふりをする   | 건강한 척하다 |
| 명사     | 명사 + の + ふりをする   | 学生のふりをする   | 학생인 척하다 |

**회화체 변형**

| 형태       | 설명           | 예시           | 의미      |
| ---------- | -------------- | -------------- | --------- |
| ふりをする | 정식 표현      | 寝たふりをする | 잔 척하다 |
| ふりする   | を 생략 (구어) | 寝たふりする   | 잔 척하다 |
| ふりして   | て형 (구어)    | 寝たふりして   | 잔 척하고 |

> 「ふり」와 비슷한 표현으로 「たぬき寝入り(たぬきねいり)」가 있다 — 자는 척하다(너구리잠). 관용적으로 자는 척할 때만 쓴다.

- 森口くんさ送ってってあげてくれない — 모리구치 군 좀 바래다줘줄 수 없어?

> 送る (おくる) — 보내다, 바래다주다
> → 送っていく — 바래다주러 가다 [+ていく(이동 방향)]
> → 送っていって — 바래다주러 가서 [+て형]
> → 送ってって — 바래다주러 가서 [구어축약(い탈락)]
> → 送ってってあげて — 바래다줘주고 [+あげる(~해주다)+て형]
> → 送ってってあげてくれない — 바래다줘줄 수 없어? [+くれない(부탁/의뢰)]
>
> **あげる + くれる 이중 수수표현**: 등장인물이 3명일 때 발생한다.
> 점장(화자)이 모리구치에게 부탁: "이이즈카(술취한 사람)를 **바래다줘**(あげる=모리구치→이이즈카) **줄 수 없어?**(くれない=모리구치→점장)"
> → あげる: 모리구치가 이이즈카에게 해주는 행위 (바래다주기)
> → くれない: 모리구치가 점장(화자)을 위해 해주는 행위 (부탁 들어주기)
> 즉, "네(모리구치)가 이이즈카한테 해주는 걸(あげる), 나(점장)를 위해 해줘(くれない)"라는 구조.
