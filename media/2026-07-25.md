### expression

- その案はちょっとなしだね。 — 그 안은 좀 아니네.

  > ない (ない) — 없다
  > → なし — 없음 [명사화]
  > → なしだ — 아니다 [+단정]
  > → なしだね — 아니네 [+확인]

- その案はちょっとありだね。 — 그 안은 좀 괜찮네.

  > ある (ある) — 있다
  > → あり — 있음 [명사화]
  > → ありだ — 괜찮다 [+단정]
  > → ありだね — 괜찮네 [+확인]

- 元カレに会って、気まずかった。 — 전 남친을 만나서 어색했다.

  > 会う (あう) — 만나다
  > → 会って — 만나서 [て형]
  >
  > 気まずい (きまずい) — 어색하다
  > → 気まずかった — 어색했다 [과거]

- 今日、体がだるい — 오늘 몸이 찌뿌둥하다.

- 最近、仕事がしんどい。 — 요즘 일이 힘들다.

- なんとなく分かる — 왠지 알 것 같다.

- ていうか、それ先に言ってよ。 — 그보다, 그거 먼저 말해줘.

  > 言う (いう) — 말하다
  > → 言って — 말해 [て형]
  > → 言ってよ — 말해줘 [+요구]

- 嫌いというより、苦手です。 — 싫다기보다, 잘 못합니다.

  > 苦手 (にがて) — 서투르다
  > → 苦手です — 잘 못합니다 [정중]

- 今日は雨です。なので、家にいます。 — 오늘은 비입니다. 그래서 집에 있습니다.

  > いる (いる) — 있다
  > → います — 있습니다 [정중]

- 雨だけど、まあいいか。 — 비가 오지만, 뭐 어때.

- さっきの動画うけた。 — 아까 그 동영상 웃겼다.

  > うける (うける) — 웃기다
  > → うけた — 웃겼다 [과거]

- 今日は休みじゃん。 — 오늘은 쉬는 날이잖아.

### Tip - じゃん

`じゃないか`가 줄어든 회화체 종조사로, 상대도 알 만한 사실을 확인하거나 동의를 구할 때 쓴다.
한국어 "~잖아"와 거의 그대로 대응한다.

**접속 형태**

| 앞말          | 예시               | 발음                 | 한글 뜻              |
| ------------- | ------------------ | -------------------- | -------------------- |
| 명사          | 今日は休みじゃん   | きょうはやすみじゃん | 오늘은 쉬는 날이잖아 |
| な형용사 어간 | それ便利じゃん     | それべんりじゃん     | 그거 편리하잖아      |
| い형용사 원형 | この店高いじゃん   | このみせたかいじゃん | 이 가게 비싸잖아     |
| 동사 원형     | 明日も来るじゃん   | あしたもくるじゃん   | 내일도 오잖아        |
| 동사 과거형   | さっき言ったじゃん | さっきいったじゃん   | 아까 말했잖아        |

> 명사·な형용사에는 `だ`를 넣지 않는다. `休みだじゃん`(✗) → `休みじゃん`(○)

**뉘앙스별 용법**

| 용법           | 예시                 | 한글 뜻       | 쓰이는 상황                    |
| -------------- | -------------------- | ------------- | ------------------------------ |
| 확인·동의 요구 | それ、おいしいじゃん | 그거 맛있잖아 | 상대도 안다고 전제하고 말할 때 |
| 지적·항의      | 先に言ったじゃん     | 먼저 말했잖아 | 상대가 잊은 것을 짚을 때       |
| 칭찬·감탄      | やるじゃん           | 제법이잖아    | 예상보다 잘했을 때             |

**정중도 비교**

| 형태             | 정중도      | 쓰는 상대        |
| ---------------- | ----------- | ---------------- |
| じゃん           | 매우 캐주얼 | 친구·가족        |
| じゃない(か)     | 캐주얼      | 친구·가까운 동료 |
| じゃないですか   | 정중        | 상사·거래처      |
| ではありませんか | 격식        | 문서·연설        |

> `じゃん`은 요코하마·간토 지방에서 퍼진 말로 젊은 층 회화 전용이다. 비즈니스 상황에서는 `じゃないですか`로 바꾼다.
> 단 `じゃないですか`도 남용하면 밀어붙이는 인상을 주므로 초면에는 피하는 게 안전하다.

- 今向かってる！ — 지금 가는 중이야!

  > 向かう (むかう) — 향하다
  > → 向かって — 향해서 [て형]
  > → 向かっている — 향하고 있다 [+진행]
  > → 向かってる — 가는 중이다 [+축약]

- じゃあ、また後で、 — 그럼, 나중에 또.

- お気になさらないでください。 — 신경 쓰지 마세요.

  > なさる (なさる) — 하시다
  > → なさらない — 하시지 않다 [부정]
  > → なさらないで — 하시지 말고 [+て형]
  > → なさらないでください — 하지 마세요 [+요청]

- 後ほど、リンクを共有します。 — 나중에 링크를 공유하겠습니다.

  > 共有する (きょうゆうする) — 공유하다
  > → 共有します — 공유하겠습니다 [정중]

### Tip - 後で와 後ほど

둘 다 "나중에"지만 격식이 다르다. 회화에서는 `後で`, 비즈니스 메일·전화에서는 `後ほど`를 쓴다.

**기본 비교**

| 일본어 | 발음     | 한글 뜻 | 격식   | 쓰는 상대        |
| ------ | -------- | ------- | ------ | ---------------- |
| 後で   | あとで   | 나중에  | 회화체 | 친구·가까운 동료 |
| 後ほど | のちほど | 나중에  | 격식체 | 상사·거래처·손님 |

> 같은 한자 `後`를 `あと`로 읽을지 `のち`로 읽을지가 갈림길이다. `後ほど`를 `あとほど`로 읽지 않는다.

**시간 간격 뉘앙스**

| 일본어   | 발음       | 한글 뜻   | 대략적 간격      |
| -------- | ---------- | --------- | ---------------- |
| 今すぐ   | いますぐ   | 지금 당장 | 즉시             |
| すぐに   | すぐに     | 곧        | 몇 분 안         |
| もうすぐ | もうすぐ   | 이제 곧   | 임박             |
| 後で     | あとで     | 나중에    | 같은 날 안       |
| 後ほど   | のちほど   | 나중에    | 같은 날 안, 격식 |
| 後日     | ごじつ     | 후일      | 며칠 뒤          |
| 改めて   | あらためて | 다시      | 날을 바꿔서      |

**예문 비교**

| 일본어                       | 한글 뜻                        | 쓰는 상대   |
| ---------------------------- | ------------------------------ | ----------- |
| じゃあ、また後で             | 그럼, 나중에 또                | 친구        |
| 後で連絡するね               | 나중에 연락할게                | 친구        |
| 後ほどご連絡いたします       | 나중에 연락드리겠습니다        | 거래처      |
| 後ほど資料をお送りします     | 나중에 자료를 보내드리겠습니다 | 상사·거래처 |
| 後日、改めてご連絡いたします | 후일 다시 연락드리겠습니다     | 거래처      |

> `後ほど`는 반드시 정중체와 함께 쓴다. `後ほど送るね`(✗)처럼 반말과 섞으면 어색하다.
> 또 `後ほど`는 막연한 "언젠가"가 아니라 보통 그날 안을 뜻하므로, 며칠 뒤라면 `後日`를 쓴다.

- お手すきの時に、ご確認をお願いします。 — 시간 나실 때 확인 부탁드립니다.

  > 願う (ねがう) — 바라다
  > → 願います — 바랍니다 [정중]
  > → お願いします — 부탁드립니다 [+겸양]

- 差し支えなければ、お名前を教えていただけますか。 — 지장이 없으시면, 이름을 알려주시겠습니까.

  > 差し支える (さしつかえる) — 지장이 있다
  > → 差し支えない — 지장이 없다 [부정]
  > → 差し支えなければ — 지장이 없으시면 [+ば형]
  >
  > 教える (おしえる) — 가르치다
  > → 教えて — 가르쳐 [て형]
  > → 教えていただく — 알려주시다 [+겸양]
  > → 教えていただける — 알려주실 수 있다 [+가능]
  > → 教えていただけますか — 알려주시겠습니까 [+정중·의문]

- 前向きに考えます。 — 긍정적으로 검토하겠습니다.

  > 考える (かんがえる) — 생각하다
  > → 考えます — 생각하겠습니다 [정중]

- 都合がつけば、参加したいです。 — 시간이 되면 참가하고 싶습니다.

  > つく (つく) — 되다
  > → つけば — 되면 [ば형]
  >
  > 参加する (さんかする) — 참가하다
  > → 参加したい — 참가하고 싶다 [희망]
  > → 参加したいです — 참가하고 싶습니다 [+정중]

- ぼちぼち行こうか。 — 슬슬 갈까.

  > 行く (いく) — 가다
  > → 行こう — 가자 [의지]
  > → 行こうか — 갈까 [+의문]

- 最近どう？　ぼちぼちかな。 — 요즘 어때? 그저 그런가.

### Tip - ぼちぼち

간사이에서 퍼진 의태어로, 문장 위치에 따라 **"슬슬"**과 **"그저 그래"** 두 뜻으로 갈린다.
서두르지도 대단하지도 않은 중간 상태를 가리키는 말이다.

**두 가지 용법**

| 용법             | 예시             | 발음             | 한글 뜻     | 판별법                 |
| ---------------- | ---------------- | ---------------- | ----------- | ---------------------- |
| 슬슬 (동작 개시) | ぼちぼち行こうか | ぼちぼちいこうか | 슬슬 갈까   | 뒤에 동사가 온다       |
| 그저 그래 (상태) | ぼちぼちかな     | ぼちぼちかな     | 그저 그런가 | 단독으로 서술어가 된다 |

> 안부 인사 `儲かってますか`(장사 잘돼요?)에 `ぼちぼちですな`로 답하는 것이 오사카 상인의 정형 대화다.
> 잘된다고 자랑하지도, 안 된다고 우는소리도 하지 않는 겸양 표현이다.

**"슬슬" 계열 비교**

| 일본어   | 발음     | 한글 뜻 | 어감                    |
| -------- | -------- | ------- | ----------------------- |
| ぼちぼち | ぼちぼち | 슬슬    | 느긋하게, 서두르지 않고 |
| そろそろ | そろそろ | 이제 곧 | 시간이 됐으니           |
| だんだん | だんだん | 점점    | 변화가 진행됨           |
| じわじわ | じわじわ | 서서히  | 천천히 스며들듯         |

**"그저 그래" 계열 비교**

| 일본어     | 발음         | 한글 뜻   | 어감              |
| ---------- | ------------ | --------- | ----------------- |
| 順調       | じゅんちょう | 순조로움  | 긍정              |
| まあまあ   | まあまあ     | 그럭저럭  | 중간, 나쁘지 않음 |
| ぼちぼち   | ぼちぼち     | 그저 그래 | 중간, 겸양이 섞임 |
| 相変わらず | あいかわらず | 여전해    | 변화 없음         |
| いまいち   | いまいち     | 별로      | 부정              |

> 두 용법 모두 친한 사이의 회화체다. 상사·거래처에는 `そろそろ参りましょうか`(슬슬 갈까요),
> `おかげさまで順調です`(덕분에 순조롭습니다)로 바꾼다.

- ぶっちゃけ、 — 솔직히 말하면,

  > ぶっちゃける (ぶっちゃける) — 솔직히 털어놓다
  > → ぶっちゃけ — 솔직히 말하면 [부사화]

- 明日、学校に行きます。 — 내일 학교에 갑니다.

  > 行く (いく) — 가다
  > → 行きます — 갑니다 [정중]

- 私は日本語が少しできます。 — 저는 일본어를 조금 할 수 있습니다.

  > できる (できる) — 할 수 있다
  > → できます — 할 수 있습니다 [정중]

- 新しいスマホが欲しいです。 — 새 스마트폰이 갖고 싶습니다.

  > 欲しい (ほしい) — 갖고 싶다
  > → 欲しいです — 갖고 싶습니다 [정중]

### Tip - がる

감정 형용사에 붙어 **"그런 티를 낸다·그렇게 보인다"**는 뜻을 더하는 접미어.
일본어는 남의 마음속을 단정하지 않으므로, 제3자의 감정을 말할 때 `がる`로 바꿔야 한다.

**왜 필요한가**

| 문장                             | 판정 | 이유                         |
| -------------------------------- | ---- | ---------------------------- |
| 私は新しいスマホが欲しい         | ○    | 화자 자신의 감정             |
| 弟は新しいスマホが欲しい         | ✗    | 남의 속마음을 단정할 수 없다 |
| 弟は新しいスマホを欲しがっている | ○    | 겉으로 드러난 모습을 서술    |
| スマホが欲しいですか             | ○    | 묻는 것은 단정이 아니다      |

**품사와 조사가 함께 바뀐다**

| 원형   | 품사     | 조사               | がる형   | 품사 | 조사                 |
| ------ | -------- | ------------------ | -------- | ---- | -------------------- |
| 欲しい | い형용사 | スマホ**が**欲しい | 欲しがる | 동사 | スマホ**を**欲しがる |
| 〜たい | い형용사 | 水**が**飲みたい   | 〜たがる | 동사 | 水**を**飲みたがる   |

> 형용사가 동사로 바뀌므로 대상 조사가 `が` → `を`로 넘어간다. 보통 `〜ている`를 붙여
> `欲しがっている`처럼 진행형으로 쓴다.

**주요 がる 동사**

| 원형       | 발음       | がる형       | 발음         | 한글 뜻        |
| ---------- | ---------- | ------------ | ------------ | -------------- |
| 欲しい     | ほしい     | 欲しがる     | ほしがる     | 갖고 싶어 하다 |
| 〜たい     | 〜たい     | 〜たがる     | 〜たがる     | 하고 싶어 하다 |
| 嫌         | いや       | 嫌がる       | いやがる     | 싫어하다       |
| 恥ずかしい | はずかしい | 恥ずかしがる | はずかしがる | 부끄러워하다   |
| 寒い       | さむい     | 寒がる       | さむがる     | 추워하다       |
| 怖い       | こわい     | 怖がる       | こわがる     | 무서워하다     |

**예문 비교**

| 일본어                     | 한글 뜻                      |
| -------------------------- | ---------------------------- |
| 弟は日本に行きたがっている | 동생은 일본에 가고 싶어 한다 |
| 娘は注射を嫌がっている     | 딸은 주사를 싫어한다         |
| 猫が寒がっている           | 고양이가 추워하고 있다       |

**がる 없이 쓰는 방법**

추측·전문 표지를 붙이면 `欲しい`를 그대로 쓸 수 있다.

| 일본어                         | 한글 뜻                              |
| ------------------------------ | ------------------------------------ |
| 弟はスマホが欲しいらしい       | 동생은 스마트폰이 갖고 싶은 모양이다 |
| 弟はスマホが欲しいみたい       | 동생은 스마트폰이 갖고 싶은 것 같다  |
| 弟はスマホが欲しいと言っている | 동생은 스마트폰이 갖고 싶다고 말한다 |

> `がる`는 관찰에 근거한 서술이라 때로 "티를 낸다"는 부정적 어감이 섞인다.
> 윗사람에게는 쓰지 않고 `〜たいそうです`나 `〜をご希望です`로 바꾼다.

- 100円しかありません。 — 100엔밖에 없습니다.

  > ある (ある) — 있다
  > → ありません — 없습니다 [정중 부정]

- 日本に住んでいます。 — 일본에 살고 있습니다.

  > 住む (すむ) — 살다
  > → 住んで — 살고 [て형]
  > → 住んでいます — 살고 있습니다 [+상태·정중]

- 右に曲がってください。 — 오른쪽으로 도세요.

  > 曲がる (まがる) — 돌다
  > → 曲がって — 돌아 [て형]
  > → 曲がってください — 도세요 [+요청]

- ここに名前を書いてください。 — 여기에 이름을 써 주세요.

  > 書く (かく) — 쓰다
  > → 書いて — 써 [て형]
  > → 書いてください — 써 주세요 [+요청]

- ここではタバコを吸ってはいけません。 — 여기서는 담배를 피우면 안 됩니다.

  > 吸う (すう) — 피우다
  > → 吸って — 피워 [て형]
  > → 吸ってはいけません — 피우면 안 됩니다 [+금지]

### Tip - いけません

`行く`의 부정형에서 나온 표현으로, 원래 뜻은 "가지 않는다"가 아니라
**"그래서는 안 된다·좋지 않다"**는 판단이다. 앞에 붙는 형태에 따라 금지·의무·필요를 만든다.

**세 가지 기본 틀**

| 형태                 | 접속            | 예시                     | 한글 뜻                 |
| -------------------- | --------------- | ------------------------ | ----------------------- |
| 〜てはいけません     | て형 + は       | ここで吸ってはいけません | 여기서 피우면 안 됩니다 |
| 〜なければいけません | ない형 + ければ | 行かなければいけません   | 가야 합니다             |
| 〜なくてはいけません | ない형 + くては | 行かなくてはいけません   | 가야 합니다             |

> 금지는 `〜ては`, 의무는 `〜なければ`·`〜なくては`로 갈린다.
> 앞의 て형이 긍정이냐 부정이냐가 뜻을 정반대로 바꾸므로 여기서 실수가 잦다.

**회화 축약형**

| 원형               | 축약형             | 한글 뜻     |
| ------------------ | ------------------ | ----------- |
| 〜てはいけない     | 〜ちゃいけない     | ~하면 안 돼 |
| 〜ではいけない     | 〜じゃいけない     | ~면 안 돼   |
| 〜なければいけない | 〜なきゃいけない   | ~해야 해    |
| 〜なくてはいけない | 〜なくちゃいけない | ~해야 해    |

> 축약형에서는 뒷부분을 아예 생략하는 일이 많다. `もう行かなきゃ`(이제 가야 해),
> `見ちゃだめ`(보면 안 돼)처럼 `いけない`가 빠져도 뜻이 통한다.

**いけません · なりません · だめです 비교**

| 일본어           | 발음             | 성격      | 쓰이는 곳 |
| ---------------- | ---------------- | --------- | --------- |
| 〜てはいけません | 〜てはいけません | 규칙·규정 | 안내·지시 |
| 〜てはなりません | 〜てはなりません | 격식·문어 | 법령·훈시 |
| 〜てはだめです   | 〜てはだめです   | 회화체    | 가족·친구 |
| 〜ないでください | 〜ないでください | 부탁      | 일상 요청 |

> `なりません`이 가장 딱딱해서 일상 회화에서는 거의 쓰지 않는다.
> 반대로 허가는 `〜てもいいです`(~해도 됩니다), `〜なくてもいいです`(~하지 않아도 됩니다)가 된다.

**허가·금지 대응표**

| 일본어                 | 한글 뜻            |
| ---------------------- | ------------------ |
| 吸ってもいいです       | 피워도 됩니다      |
| 吸ってはいけません     | 피우면 안 됩니다   |
| 行かなくてもいいです   | 가지 않아도 됩니다 |
| 行かなければいけません | 가야 합니다        |

- まだ食べていません。 — 아직 안 먹었습니다.

  > 食べる (たべる) — 먹다
  > → 食べて — 먹고 [て형]
  > → 食べていません — 안 먹었습니다 [+미완료·정중 부정]

- 窓が開いています。 — 창문이 열려 있습니다.

  > 開く (あく) — 열리다
  > → 開いて — 열려 [て형]
  > → 開いています — 열려 있습니다 [+상태·정중]

### Tip - 開く의 두 읽기 (あく·ひらく)

같은 한자를 `あく`와 `ひらく`로 읽고, 뜻과 자·타동사 성격이 다르다.
`あく`는 **막힌 것에 틈이 생긴다**, `ひらく`는 **접힌 것이 펼쳐진다**는 이미지다.

**て형은 표기가 같아진다**

| 원형   | 발음   | て형 표기 | て형 발음 | 자·타동사     |
| ------ | ------ | --------- | --------- | ------------- |
| 開く   | あく   | 開いて    | あいて    | 자동사만      |
| 開く   | ひらく | 開いて    | ひらいて  | 자동사·타동사 |
| 開ける | あける | 開けて    | あけて    | 타동사만      |

> `開いて`는 `あいて`·`ひらいて` 두 가지로 읽힌다. 표기만으로는 구분되지 않으므로
> 조사와 목적어를 보고 판단해야 한다. `開けて`는 표기가 달라 헷갈리지 않는다.

**읽기 판별법**

| 단서                 | 읽기     | 예시       | 한글 뜻     |
| -------------------- | -------- | ---------- | ----------- |
| を가 붙는다          | ひらいて | 本を開いて | 책을 펴서   |
| が + 문·창·구멍·자리 | あいて   | 窓が開いて | 창문이 열려 |
| が + 꽃·차이·시야    | ひらいて | 花が開いて | 꽃이 피어   |

> `あく`에는 타동사가 없으므로 `を`가 보이면 무조건 `ひらく`다. 이것이 가장 확실한 단서다.

**ひらく만 쓰는 경우**

| 일본어     | 발음           | 한글 뜻         |
| ---------- | -------------- | --------------- |
| 本を開く   | ほんをひらく   | 책을 펴다       |
| 傘を開く   | かさをひらく   | 우산을 펴다     |
| 会議を開く | かいぎをひらく | 회의를 열다     |
| 店を開く   | みせをひらく   | 가게를 개업하다 |
| 花が開く   | はながひらく   | 꽃이 피다       |
| 差が開く   | さがひらく     | 차이가 벌어지다 |

**あく를 쓰는 경우**

| 일본어   | 발음       | 한글 뜻            |
| -------- | ---------- | ------------------ |
| 窓が開く | まどがあく | 창문이 열리다      |
| 店が開く | みせがあく | 가게가 영업을 열다 |
| 穴が開く | あながあく | 구멍이 나다        |
| 席が開く | せきがあく | 자리가 나다        |

> `店`은 읽기에 따라 뜻이 갈린다. `店を開く(ひらく)`는 개업, `店が開く(あく)`는 오늘 영업 시작이다.

**둘 다 가능한 경우**

문·창처럼 여닫는 것은 양쪽이 다 되지만, `ひらく`가 더 격식 있고 "양쪽으로 크게 벌어진다"는 느낌이 강하다.

| 일본어         | 읽기       | 쓰이는 곳      |
| -------------- | ---------- | -------------- |
| ドアが開きます | ひらきます | 전철 안내 방송 |
| ドアが開きます | あきます   | 일상 회화      |

- 明日から勉強することにしました。 — 내일부터 공부하기로 했습니다.

  > する (する) — 하다
  > → しました — 했습니다 [정중 과거]

- 来月日本に行くことになりました。 — 다음 달에 일본에 가게 되었습니다.

  > なる (なる) — 되다
  > → なりました — 되었습니다 [정중 과거]

### Tip - ことにする와 ことになる

동사 원형에 붙어 결정을 나타내는 짝 표현. **누가 정했는지**로 갈린다.
`する`는 내가 정한 것, `なる`는 밖에서 정해진 것이다.

**기본 대비**

| 형태         | 결정 주체 | 예시                       | 한글 뜻                |
| ------------ | --------- | -------------------------- | ---------------------- |
| 〜ことにする | 나        | 勉強することにしました     | 공부하기로 했습니다    |
| 〜ことになる | 외부·상황 | 日本に行くことになりました | 일본에 가게 되었습니다 |

> 회사 발령·학교 결정처럼 내 의지 밖의 일에 `ことにする`를 쓰면 주제넘게 들리고,
> 반대로 내가 정한 일에 `ことになる`를 쓰면 책임을 회피하는 인상이 된다.

**겸양 화법으로서의 ことになる**

실제로는 본인이 원해서 지원했더라도 결과를 알릴 때는 `ことになりました`를 쓰는 일이 많다.
자기 뜻을 앞세우지 않는 일본어다운 완충 화법이다.

| 일본어                             | 한글 뜻             | 상황          |
| ---------------------------------- | ------------------- | ------------- |
| 転職することになりました           | 이직하게 되었습니다 | 지인에게 보고 |
| 結婚することになりました           | 결혼하게 되었습니다 | 청첩·공지     |
| 担当させていただくことになりました | 담당하게 되었습니다 | 업무 인사     |

**활용형 정리**

| 형태               | 예시                      | 한글 뜻                 |
| ------------------ | ------------------------- | ----------------------- |
| 〜ないことにする   | 行かないことにしました    | 가지 않기로 했습니다    |
| 〜ないことになる   | 行かないことになりました  | 가지 않게 되었습니다    |
| 〜ことになっている | 3時からことになっています | 3시부터로 되어 있습니다 |
| 〜ということになる | 中止ということになります  | 중지라는 셈이 됩니다    |

> `〜ことになっている`는 규정·예정을 전할 때 쓴다. `会議は3時からということになっています`
> (회의는 3시부터로 되어 있습니다)처럼 "내가 정한 게 아니라 그렇게 정해져 있다"는 뜻이다.

**비슷한 짝 표현**

`する`와 `なる`의 대비는 다른 문형에도 그대로 적용된다.

| する 쪽      | なる 쪽      | 한글 뜻                   |
| ------------ | ------------ | ------------------------- |
| 〜ようにする | 〜ようになる | ~하도록 하다 / ~하게 되다 |
| 〜ことにする | 〜ことになる | ~하기로 하다 / ~하게 되다 |
| 〜くする     | 〜くなる     | ~하게 하다 / ~해지다      |

> `する`는 의지적 작용, `なる`는 자연스러운 변화·결과라는 구도가 일본어 전반에 깔려 있다.

### Tip - お見せする (겸양어 공식)

`お + 동사 ます형 + する`는 **내 행동을 낮춰 상대를 높이는** 겸양어 공식이다.
`お見せする`는 `見せる`(보여주다)를 이 틀에 넣은 형태로 "보여드리다"가 된다.

**정중도 단계**

| 일본어           | 발음             | 한글 뜻          | 정중도 |
| ---------------- | ---------------- | ---------------- | ------ |
| 見せる           | みせる           | 보여주다         | 반말   |
| 見せます         | みせます         | 보여줍니다       | 정중   |
| お見せします     | おみせします     | 보여드립니다     | 겸양   |
| お見せいたします | おみせいたします | 보여드리겠습니다 | 격식   |

**같은 공식으로 만드는 겸양어**

| 원형   | 발음     | 겸양형       | 발음           | 한글 뜻      |
| ------ | -------- | ------------ | -------------- | ------------ |
| 願う   | ねがう   | お願いします | おねがいします | 부탁드립니다 |
| 送る   | おくる   | お送りします | おおくりします | 보내드립니다 |
| 伝える | つたえる | お伝えします | おつたえします | 전해드립니다 |
| 持つ   | もつ     | お持ちします | おもちします   | 들어드립니다 |
| 見せる | みせる   | お見せします | おみせします   | 보여드립니다 |

> 한자어에는 `お`가 아니라 `ご`가 붙는다. `ご連絡します`, `ご説明します`.
> 더 낮추려면 `します` → `いたします`로 바꾼다.

**보다·보여주다의 방향별 경어**

같은 "보다"라도 주체가 나인지 상대인지에 따라 완전히 다른 말을 쓴다.

| 방향            | 표현               | 발음               | 한글 뜻      |
| --------------- | ------------------ | ------------------ | ------------ |
| 내가 보여준다   | お見せします       | おみせします       | 보여드립니다 |
| 내가 본다       | 拝見します         | はいけんします     | 보겠습니다   |
| 상대가 보여준다 | 見せてくださいます | みせてくださいます | 보여주십니다 |
| 상대가 본다     | ご覧になります     | ごらんになります   | 보십니다     |

> `拝見`과 `ご覧`은 공식으로 만들 수 없는 **특수 경어**다. 통째로 외워야 한다.
> `お見せします`처럼 공식으로 만드는 것과 구분해서 익힌다.

**실무 예문**

| 일본어                 | 한글 뜻                 |
| ---------------------- | ----------------------- |
| 資料をお見せします     | 자료를 보여드리겠습니다 |
| 実物をお見せいたします | 실물을 보여드리겠습니다 |
| 資料を拝見しました     | 자료를 봤습니다         |
| こちらをご覧ください   | 이쪽을 보십시오         |

- 道に迷いました。 — 길을 잃었습니다.

  > 迷う (まよう) — 헤매다
  > → 迷いました — 헤맸습니다 [정중 과거]

- 今後、日本語力をさらに伸ばしていきたいです。 — 앞으로 일본어 실력을 더욱 늘려가고 싶습니다.

  > 伸ばす (のばす) — 늘리다
  > → 伸ばして — 늘려 [て형]
  > → 伸ばしていきたい — 늘려가고 싶다 [+계속·희망]
  > → 伸ばしていきたいです — 늘려가고 싶습니다 [+정중]

- カフェの雰囲気が好きなので、よく行きます。 — 카페 분위기가 좋아서 자주 갑니다.

  > 行く (いく) — 가다
  > → 行きます — 갑니다 [정중]

### Tip - なので

이유를 나타내는 `ので`의 앞에 `な`가 붙은 형태. `な`는 명사·な형용사에만 필요하다.
동사·い형용사에는 `な` 없이 `ので`가 그대로 붙는다.

**접속 규칙**

| 앞말      | 접속          | 예시       | 한글 뜻    |
| --------- | ------------- | ---------- | ---------- |
| な형용사  | 어간 + なので | 好きなので | 좋아하니까 |
| 명사      | 명사 + なので | 雨なので   | 비니까     |
| い형용사  | 원형 + ので   | 高いので   | 비싸니까   |
| 동사      | 원형 + ので   | 行くので   | 가니까     |
| 동사 과거 | た형 + ので   | 行ったので | 갔으니까   |

> `好きので`(✗) → `好きなので`(○). 명사·な형용사에 `な`를 빼먹는 것이 가장 흔한 실수다.
> `だので`(✗)도 안 된다. 단정 `だ`는 `な`로 바뀐다.

**문장 앞에 세우는 なので**

원래 `なので`는 문장 안에서 잇는 표현이지만, 회화·SNS에서는 문장 앞에 세워 접속사처럼 쓴다.

| 형태             | 예시                               | 격식     |
| ---------------- | ---------------------------------- | -------- |
| 문장 안 (정통)   | 今日は雨なので、家にいます         | 표준     |
| 문장 앞 (회화체) | 今日は雨です。なので、家にいます   | 구어·SNS |
| 문장 앞 (격식)   | 今日は雨です。ですから、家にいます | 격식     |
| 문장 앞 (문서)   | 今日は雨です。そのため、家にいます | 문서     |

> 문장 앞의 `なので`는 격식 있는 글이나 비즈니스 메일에서는 피하고
> `ですから`·`そのため`·`したがって`로 바꾼다.

**ので와 から 비교**

| 형태 | 어감            | 쓰이는 곳        | 예시                     |
| ---- | --------------- | ---------------- | ------------------------ |
| ので | 객관적·부드러움 | 정중한 설명·사과 | 用事があるので失礼します |
| から | 주관적·직접적   | 회화·주장        | 用事があるから帰るね     |

> 부탁하거나 사과할 때는 `ので`가 안전하다. `から`는 "내가 그렇게 판단했으니까"라는
> 강한 어감이 있어 따지는 인상을 줄 수 있다.

**같은 자리에 오는 이유 표현**

| 일본어   | 발음     | 어감             | 격식 |
| -------- | -------- | ---------------- | ---- |
| から     | から     | 주관적, 직접적   | 회화 |
| ので     | ので     | 객관적, 부드러움 | 보통 |
| ため     | ため     | 객관적, 딱딱함   | 문서 |
| おかげで | おかげで | 좋은 결과의 원인 | 감사 |
| せいで   | せいで   | 나쁜 결과의 원인 | 불만 |

> `おかげで`와 `せいで`는 결과의 좋고 나쁨이 정해져 있다.
> `雨のせいで中止になった`(비 때문에 취소됐다) / `皆さんのおかげで成功しました`(모두 덕분에 성공했습니다)
